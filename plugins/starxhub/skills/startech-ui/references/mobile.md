# 星辰移动端规范（H5 + 小程序）

> 提炼自《星辰 MOBILE_SPEC v1.0》。具体数值以 `assets/presets/startech/mobile/tokens.css` 与 `miniapp/styles/tokens.wxss` 为准。

## 1. rpx / px 双轨

- H5 用 px，小程序用 rpx，按设计稿基准宽度换算（通常 750rpx = 设计稿宽度）。
- 两套单位各写各的，不在同一文件混用；换算表写进文档，避免每次现算。
- 三条硬规则：基准统一、换算集中、禁止魔法数字。

## 2. 字体与触控

- 标题正文同族（`--hx-font-sans`），系统无衬线；字阶靠 size + weight，不靠字体族切换。
- 触控热区 ≥ 44×44；下拉箭头区触控态放大到 36×36（视觉 28×28）。

## 3. 安全区（平台差异最大）

- 小程序：用 `env(safe-area-inset-*)` 配合原生安全区适配；顶部状态栏、底部 TabBar 各自留白。
- H5：刘海屏同样用 `env()`，但浏览器兼容性要加常量兜底。
- 两端不要共用同一段安全区代码——文件可以同源，落地要分开。

## 4. 暗色实现（双端不同）

- 星辰有完整 dark 覆盖（23 项）。H5 跟随 class，小程序跟随系统或自建状态，触发方式不同，不要共用同一段代码。

## 5. 页面结构四层

```text
① 安全区 / 状态栏
② 导航层（返回 + 标题 + 操作）
③ 内容层（卡片 / 列表 / 表单）
④ 固定操作层（底部按钮 / TabBar）
```

## 6. 小程序专属

- WXML 里保留与 Web 相同的类名语义（历史类为 `st-*`），样式由 `.wxss` 提供。
- `@import` 必须是 `.wxss` 后缀；令牌副本由 `sync-tokens.mjs` 单向生成，禁止手改 `.wxss` 副本。
- 组件放 `components/` 分目录（如 st-select / st-input / st-textarea / st-tabs / st-chart）。

## 7. H5 专属

- 静态预览页的 CSS 必须与 HTML 同目录（预览服务禁止跨上级目录取资源，403）。
- 原生 `<select>` 保持浏览器行为，不要被组件展示块污染。
- 与后台端共用组件库时，端样式放在组件样式之后引入。
- 静态预览 CSS 由 `sync-styles.mjs` 生成，改完令牌记得跑 `npm run sync:skills`。

## 8. 双端差异对照（落地时逐项确认）

| 项 | H5 | 小程序 |
|---|---|---|
| 单位 | px | rpx |
| 样式后缀 | `.css` | `.wxss` |
| 暗色触发 | class / media | 系统 API / 自建状态 |
| 安全区 | `env()` + 兜底 | 原生适配 + `env()` |
| 组件形态 | Vue SFC / 原生 DOM | 原生组件 |
| 令牌同步 | 真源直接引用 | 脚本生成副本 |

## 9. 验收清单

- [ ] rpx/px 换算表齐全，无魔法数字
- [ ] 触控热区 ≥ 44×44
- [ ] 安全区两端分别实现且已真机验证
- [ ] 无 serif / 宋体残留（含 SVG `<text>`）
- [ ] 原生 select 未被组件样式污染
- [ ] 令牌 WXSS 副本由脚本生成且字节一致
