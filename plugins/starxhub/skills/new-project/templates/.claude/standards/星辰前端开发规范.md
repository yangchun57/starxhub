## 0. 一页速览（结论先行）

1. **三层样式、单一事实来源**：`tokens.css` 只放变量，`common.css` 只放 reset / 骨架 / 栅格 / 工具类，`components.css` 放全部 `hx-` 组件类。Vue SFC **不写 `<style>`**，静态展示页共用同一套 CSS。
2. **颜色只走变量**：业务 UI 中禁止出现 `#RRGGBB`、`rgb()` 字面量，一律 `var(--hx-*)`；例外仅限装饰性 SVG 与横幅渐变（已登记，见 §4.4）。
3. **外壳锁视口、内容各自滚**：`.hx-app` 锁 `100dvh`，`.hx-nav` 与 `.hx-content` 是两个独立滚动容器；`.hx-content > *` 必须 `flex-shrink: 0`，否则长内容会被静默裁掉。
4. **浮层一律 Teleport 到 body**：下拉 / 弹窗用 `position: fixed`，层级 100 / 200，避免被 `overflow: hidden` 的卡片裁切。
5. **组件分四层**：`layout` 骨架、`base` 无业务语义控件、`biz` 业务复合件、`charts` 纯 SVG 图表。基础件可整体换成 Element Plus / Naive UI，页面无需重写。
6. **数据契约固定**：所有响应包成 `ApiResult<T>`（`code === 0` 为成功），列表用 `PageResult<T>`；接 .NET8 时只替换 `mock/index.ts` 或 `useRequest` 的 loader。
7. **改令牌的三步动作**：改 `src/styles/tokens.css` → `npm run sync:showcase` → 更新本文 §3 表格。漏掉第 2 步预览页会用到旧样式。

## 1. 设计定位与原则

### 1.1 定位

面向内部运营后台（订单 / 商品 / 客户 / 营销 / 消息 / 设置），视觉基调为「**活泼但不轻浮、正式但不沉闷**」：深色导航压住整体气场，浅色工作区保证长时间阅读舒适，电光蓝作为唯一强调色，彩色图标块与低饱和渐变横幅提供活力。

### 1.2 六条原则

| # | 原则 | 落地方式 | 等级 |
| --- | --- | --- | --- |
| P1 | 令牌驱动 | 颜色 / 圆角 / 间距 / 字号 / 动效全部来自 `tokens.css` | MUST |
| P2 | 单一事实来源 | Vue 工程与 `showcase/` 静态页引用同一份 CSS，静态页副本由脚本生成、禁止手改 | MUST |
| P3 | 结构与外观分离 | SFC 只负责 DOM 与状态，外观靠 `hx-` 类名；不在组件内写样式 | MUST |
| P4 | 语义优先 | 状态色表达业务含义（成功 / 警告 / 危险 / 信息），不用「红=坏、绿=好」的裸色值 | MUST |
| P5 | 可替换 | `base/` 与 `charts/` 是可插拔适配层，业务视图只依赖组件名与 Props | SHOULD |
| P6 | 无障碍基线 | 可聚焦、可键盘操作、暗色可读、尊重 `prefers-reduced-motion` | SHOULD |

> **金额 / 涨跌补充约定**：本框架是运营后台，`--hx-success` / `--hx-danger` 表达业务成败，不表示行情涨跌。若后续接入股票 / 行情模块，须按 A 股惯例改用「涨红跌绿」并单独定义令牌，不得直接复用本套语义色。

## 2. 样式架构与目录

### 2.1 加载顺序（MUST，不可调换）

```html
<link rel="stylesheet" href="/src/styles/tokens.css" />      <!-- 1. 变量 -->
<link rel="stylesheet" href="/src/styles/common.css" />      <!-- 2. reset / 骨架 / 栅格 / 工具类 -->
```

## 4. 色彩使用规范

### 4.1 配对规则（MUST）

| 场景 | 前景 | 背景 |
| --- | --- | --- |
| 主按钮 | `--hx-text-on-dark` | `--hx-brand`（悬停 `--hx-brand-hover`） |
| 主按钮（次强调） | `--hx-brand` | `--hx-brand-soft`（soft 变体） |
| 状态标签 | `--hx-success` / `--hx-warning` / `--hx-danger` / `--hx-info` / `--hx-brand` | 对应的 `-soft` |
| 卡片正文 | `--hx-text-body` | `--hx-surface` |
| 表头 | `--hx-text-secondary` | `--hx-surface-subtle` |
| 焦点环 | — | `0 0 0 3px var(--hx-brand-soft)` + `border-color: var(--hx-brand)` |
| 深底导航选中 | `--hx-text-on-dark` | `--hx-brand` |

### 4.2 状态语义映射（MUST）

状态文案 → 色调由 `StatusTag.vue` 的 `MAP` 与 `types/index.ts` 的 `Tone` 统一约束，禁止页面里自行判断颜色。

| Tone | 典型业务状态 |
| --- | --- |
| `success` | 已完成、在售、进行中 |
| `warning` | 待付款、金卡客户、库存预警 |
| `danger` | 已取消、退款中、已下架、超期工单 |
| `brand` | 处理中、未开始、企业客户、订单审核 |
| `info` | 已发货、草稿、已结束、普通/银卡客户 |

### 4.3 对比度与暗色（SHOULD）

- 正文与背景对比度目标 ≥ 4.5:1；大号数值 / 标题 ≥ 3:1。
- Dark 模式**只覆盖表面与文本**，语义色保持同一色相；新增语义色必须同时补 `-soft` 的暗色值。
- 暗色滚动条：`.hx-content` 用 `scrollbar-color: var(--hx-border) transparent`，`.hx-nav` / `.hx-sidebar-foot` 用 `--hx-sidebar-track`，避免系统白条。

### 4.4 允许的字面量色值（例外清单，MUST 只限这些）

| 位置 | 内容 | 原因 |
| --- | --- | --- |
| `AppSidebar.vue` 品牌 / 头像 SVG | `var(--hx-brand)`、`#fff`、`#3E6FD8`、`#DCE8FF`、`var(--hx-accent-yellow)` | 品牌插画资产，非 UI 控件 |
| `DashboardView.vue` 横幅装饰 SVG | `#fff` + `fill-opacity` | 半透明装饰层 |
| `components.css` `.hx-banner` | `#dfedff → #d9f6f0`；Dark `#1b3559 → #17453f` | 低饱和双色渐变，无对应令牌 |
| `components.css` `.hx-modal-mask` | `rgba(12, 22, 38, 0.45)` | 遮罩透明度 |
| `StatCard.vue` / `TodoItem.vue` 的图标映射 | 一律 `var(--hx-*)` | 不算字面量 |

> 新增主题 / 换品牌色时，上表前 4 处需要人工同步，其余全部自动跟随令牌。

## 5. 排版规范

| 规则 | 要求 | 等级 |
| --- | --- | --- |

## 7. 滚动容器与层级规范（重点 / 历史回归项）

### 7.1 四个容器（MUST）

| 容器 | 关键声明 | 行为 |
| --- | --- | --- |
| `.hx-app` | `height: 100vh; height: 100dvh; overflow: hidden` | 锁视口，页面整体**不滚动** |
| `.hx-sidebar` / `.hx-main` | `height: 100%; min-height: 0; overflow: hidden` | 两栏各自固定 |
| `.hx-nav` | `flex: 1 1 auto; min-height: 0; overflow-y: auto; overscroll-behavior: contain` | **侧栏唯一滚动区**，品牌与用户区固定 |
| `.hx-content` | `flex: 1 1 auto; min-height: 0; overflow: auto; gap: var(--hx-gap-section)` | **内容唯一滚动区** |

配套硬规则：

```css
/* flex 列容器默认会压缩子项；卡片又是 overflow:hidden，长内容会被直接裁掉且不出现滚动条 */
.hx-content > * { flex-shrink: 0; }

/* 目录树 / 多行代码保留 ASCII 对齐，窄屏横向滚动 */
pre.hx-code { white-space: pre; word-break: normal; overflow-x: auto; font-variant-ligatures: none; }
```

- `.hx-sidebar-foot` 用 `max-height: 52%` + 自身滚动；`.hx-nav-item` 用 `flex: 0 0 42px`，导航项不会被压缩。
- 静态预览 `showcase/app.js` 在 `render()` 中保存 / 恢复 `.hx-nav.scrollTop`，并把 `.hx-content.scrollTop` 归零 —— 切页时菜单滚动位置不丢（Vue 工程因侧栏不重建而无此问题）。

### 7.2 浮层与 z-index（MUST）

| 层级 | 值 | 使用者 |
| --- | --- | --- |
| 局部装饰 | `1` | `.hx-banner-btn` |
| 模态遮罩 | `100` | `.hx-modal-mask`（`Teleport to="body"`） |
| 下拉浮层 | `200` | `.hx-select-panel`（`Teleport to="body"`、`position: fixed`） |
| 预留 | `300` | Toast / 全局提示（尚未实现，不预定义类名） |

浮层必须挂到 `body`：祖先链上 `.hx-card`、`.hx-content`、`.hx-app` 都带 `overflow: hidden`，任何 `absolute` 浮层都会被裁切。

## 9. 组件规范

**通用约定**
- 所有 SFC 使用 `<script setup lang="ts">`，**不写 `<style>`**。
- 双向绑定统一用 `defineModel<T>()`，父级用 `v-model`；事件用 `defineEmits`。
- 视觉状态一律 `is-active` / `is-selected` / `is-disabled` / `is-open` / `is-up` / `is-on`，不用内联样式表达状态。
- 允许内联 `style` 的场景仅限：动态宽高、动态颜色（来自令牌变量字符串）、进度百分比。

### 9.1 layout 层

| 组件 | Props / Slots | 结构与规则 |
| --- | --- | --- |
| `AppShell.vue` | 无 | `.hx-app` → `AppSidebar` + `.hx-main` → `AppTopbar` + `main.hx-content` → `<router-view>`（组件挂 `.hx-fade-in`）。**唯一允许出现 `.hx-app` 的地方** |
| `AppSidebar.vue` | 无 | 遍历 `NAV_ITEMS`：有 `group` 时插入 `.hx-nav-group`；`route.path === item.path` 时加 `is-active`；`badge` 渲染 `.hx-nav-badge`。底部含目标进度卡、指南卡、用户信息 |
| `AppTopbar.vue` | 无 | 面包屑 `meta.crumb / label`、标题 `NAV_ITEMS.label`；搜索框、月份 `HxSelect`、主题切换（图标 `moon` / `sun`）、通知（`.hx-dot`）、组织 `HxSelect` |
| `PageHeader.vue` | `title: string`（必填）、`desc?: string`；具名 slot `actions` | `.hx-page-head` + `.hx-page-title` + `.hx-page-desc`；右侧放主/次操作按钮 |

### 9.2 base 层（基础控件）

#### HxIcon
`name: string`（必填）、`size?: number = 18`；输出 `18×18` viewBox 线性 SVG，`stroke="currentColor"`，颜色由父级 `color` 决定。未知 key 回退 `grid`。

#### HxButton

| Prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `variant` | `primary \| secondary \| ghost \| soft \| danger` | `primary` | 对应 `.hx-btn--primary` 等变体 |
| `size` | `sm \| md \| lg` | `md` | `sm=30px`、`md=36px`、`lg=40px` |
| `block` | `boolean` | `false` | 宽度 100% |
| `disabled` | `boolean` | `false` | `opacity: 0.5` + `cursor: not-allowed` |
| `iconName` | `string` | — | 前置 14px 图标 |

默认 slot 为文案；组件未声明 emits，原生事件经 Vue 属性透传落到根 `<button>`，父级直接 `@click` 即可。主操作一屏只放一个 `primary`；危险操作用 `danger` 且需二次确认。

#### HxInput
`placeholder?: string = '请输入'`、`iconName?: string`、`type?: string = 'text'`、`width?: number`、`disabled?: boolean = false`；`defineModel<string>('')`。外层 `.hx-input-wrap`，带图标时加 `.hx-input--with-icon`（左内边距 34px）。焦点态：`--hx-brand` 边框 + `0 0 0 3px var(--hx-brand-soft)`。

#### HxSelect（自定义下拉，重点）

| Prop | 类型 | 默认 |
| --- | --- | --- |
| `options` | `(string \| { label: string; value: string })[]` | 必填 |
| `width` | `number` | `150` |
| `placeholder` | `string` | `请选择` |
| `label` | `string` | `''`（浮层顶部说明） |
| `disabled` | `boolean` | `false` |

`defineModel<string>('')`；挂载时若值为空，自动同步为**首项 value**，避免「看着选中、值却为空」。

DOM 与状态：

```
.hx-select-wrap(.is-open) > button.hx-select.hx-select-trigger[role=combobox]
                         > .hx-select-value(.is-placeholder) + .hx-select-arrow
Teleport → body > .hx-select-panel(.is-up)[role=listbox]
                > .hx-select-label + .hx-select-list
                  > .hx-select-option(.is-selected / .is-active / .is-disabled)[role=option]
                    > .hx-select-option-text + .hx-select-option-check
```

| 状态 | 外观 |
| --- | --- |
| 默认选项 | `min-height: 34px`、圆角 `7px`、文字 `--hx-text-body` |
| 悬停 / 键盘高亮 | 背景 `--hx-surface-subtle`、文字 `--hx-text-primary` |
| 选中 | 背景 `--hx-brand-wash`、文字 `--hx-brand`、字重 600、左侧 3px 品牌竖条（`.hx-select-option::before`）、右侧 14px 勾选图标 |
| 禁用 | 文字 `--hx-text-muted`、无悬停背景 |
| 空列表 | `.hx-select-empty` 显示「暂无可选项」 |

> 选项级 `.is-disabled` 属于样式预留；当前组件仅提供整体 `disabled`，暂不支持单项禁用。

交互契约（MUST）：`↑` / `↓` 移动高亮并滚动入视；`Enter` / `Space` 选中；`Esc` 关闭；外部点击关闭；滚动（capture 阶段）与 resize 时按触发器 `getBoundingClientRect()` 重算 `left/top/minWidth`；下方空间不足且上方足够时 `is-up` 向上翻转；`max-width: min(360px, calc(100vw - 32px))`，列表 `max-height: 232px` 内部滚动。静态规范展示使用 `.hx-select-panel--inline`（`position: static`、无动画、弱阴影）。

> **禁止回退到原生 `<select>` / `<option>`**：系统绘制的选项无法控制圆角、行高、悬停、选中标记与暗色。

#### HxTag
`tone?: Tone = 'info'`、`pill?: boolean = false`；类名 `.hx-tag` + `.hx-tag--brand` 等变体（由 `tone` 决定），胶囊加 `.hx-tag--pill`，描边变体 `.hx-tag--outline`。默认 slot 为文案。

#### HxCard
`title?: string`、`sub?: string`、`link?: string`、`linkText?: string = '查看全部'`；默认 slot 内容，具名 slot `extra` 覆盖右上链接区。结构：`.hx-card` →（有 `title` 时）`.hx-card-head` + `.hx-divider` → 默认 slot。卡片自带 `overflow: hidden`，内部长内容必须自己提供滚动。

#### HxPagination
`total?: number = 2486`、`pageSize?: number = 6`、`span?: number = 3`；`defineModel<number>(1)`。显示 `span` 个页码 + 「下一页」；`pageCount = ceil(total / pageSize)`，当前页用 `.hx-page.is-active`。

#### HxEmpty / HxModal
- `HxEmpty`：`text?: string = '暂无数据'`，`.hx-empty` 居中，图标 56px、`opacity: 0.6`。数据表无数据时**必须**显示空态。
- `HxModal`：`open?: boolean = false`、`title?: string = '提示'`；`emits: close / confirm`；默认 slot 内容、具名 slot `footer`。`Teleport to="body"`，`.hx-modal-mask` 点击自身关闭，宽 `min(480px, calc(100vw - 32px))`。

### 12.1 响应包装（MUST）

```ts
export interface ApiResult<T> { code: number; data: T; message: string }
export interface PageResult<T> { items: T[]; total: number; page: number; pageSize: number }
```

`code === 0` 为成功，其他值由 `useRequest` 抛 `Error(message)`。所有 mock / 真实接口一律返回 `ApiResult<T>`。

### 12.2 请求层

```ts
const { data, loading, error, refresh } = useRequest<T>(loader, initial?)
```

- `loader: () => Promise<ApiResult<T>>`，调用即自动执行一次，`refresh()` 可重跑。
- `data` 声明为 `shallowRef<T | undefined>(initial)`，保留泛型 T 原样（避免 `ref` 深层解包把 DTO 嵌套对象拆掉，这是已修过的类型错误）。
- `useRequest` 内部不缓存、不做并发去重；需要全局状态 / 缓存时再引入 Pinia 或 `@vueuse/core`，**不要改 `useRequest` 签名**。

### 12.3 接 .NET8 的两种方式

1. 最小改动：把 `src/mock/index.ts` 里 `api.*` 的实现换成 `fetch('/api/...')` 并保留 `ApiResult<T>` 形状（Vite 已配 `/api` → `http://localhost:5000` 代理）。
2. 规范做法：新增 `src/api/http.ts` 统一封装，`useRequest(() => http.get<ApiResult<T>>('/api/orders'))`；视图与组件零改动。

`types/index.ts` 中的 DTO（`Order` / `Product` / `Customer` / `Campaign` / `MessageItem` / `Activity` / `Metric` / `TrafficSource`）与后端 DTO 一一对应，字段命名保持 camelCase。

## 13. 主题与路由

### 13.1 主题切换（MUST）

```ts
document.documentElement.dataset.theme = 'dark'   // 'light' | 'dark'
localStorage.setItem('hx-theme', theme)           // key 固定为 hx-theme
```

`useTheme.ts` 在模块加载时立即 `apply()` 一次，避免首屏闪白；返回 `{ theme, toggle, set }`。Dark 只覆盖 23 个表面 / 文本 / 柔和底令牌，语义色与尺寸不变。

### 13.2 路由（MUST）

- `createWebHashHistory()`：无需服务端 rewrite，`dist/` 直接放进 .NET8 `wwwroot` 任意子目录即可（`base: './'`）。
- `NAV_ITEMS` 是**导航、面包屑、路由三者的共同配置源**；每项含 `key / label / path / icon`，可选 `group / badge`。
- 每个路由必须带 `meta.title` 与 `meta.crumb`；未匹配路径统一 `redirect: '/dashboard'`。
- 新增页面 5 步：在 `views/` 下新建视图组件 → 追加 `NAV_ITEMS` → 追加 `routes`（含 meta）→ 用 §11.2 模板搭区块 → `npm run build` + `npm run sync:showcase`。
