# 安全编码规范

> 单一事实来源：本文件由历史 topics 手工分片回并生成，章节标题与分片文件名一一对应。
> `topics/` 由 `split-standards.py` 按 `## ` 重建，禁止手改分片；分片正文标题已整体降两级，避免被误切。

## 概述

#### 适用范围

本规范适用于所有涉及认证授权、文件上传、接口访问控制的代码。

#### 核心原则

1. **最小权限原则**：所有管理接口必须显式标注 `[Authorize]`，默认拒绝未授权访问
2. **纵深防御原则**：前端校验 + 后端校验 + 数据库约束三层防护
3. **零信任原则**：所有外部输入（文件、参数、Header）均需校验和过滤
4. **安全默认原则**：配置项缺失或无效时，应用应拒绝启动而非降级运行

#### 问题分类

| 级别 | 说明 | 示例 |
|------|------|------|
| Critical | 可直接导致权限提升、数据泄露 | 管理接口无授权、JWT 密钥过短 |
| High | 可被利用但需要特定条件 | 文件上传无类型校验、无限流 |
| Medium | 潜在风险但利用难度较高 | HTTP 状态码被掩盖 |

#### 强制检查清单

- [ ] 所有 Controller 方法是否标注 `[Authorize]` 或 `[AllowAnonymous]`
- [ ] JWT 密钥长度是否 ≥ 256 位
- [ ] 生产环境是否强制 HTTPS
- [ ] 文件上传是否校验大小和类型
- [ ] 公开接口是否配置速率限制

## 接口授权规范

#### 强制规则

##### 1. Controller 必须显式标注授权

**所有 Controller 类或方法必须标注 `[Authorize]` 或 `[AllowAnonymous]`，禁止遗漏。**

```csharp
// ✅ 正确：类级别标注
[Authorize(Roles = "Admin")]
[ApiController]
[Route("api/[controller]")]
public class AdminController : ControllerBase
{
    [HttpDelete("{id}")]
    public async Task<ApiResult<bool>> Delete(long id)
    {
        // 仅 Admin 角色可访问
    }
}

// ✅ 正确：方法级别标注
[ApiController]
[Route("api/[controller]")]
public class RegistrationController : ControllerBase
{
    [AllowAnonymous]  // 公开接口显式标注
    [HttpPost]
    public async Task<ApiResult<long>> Register([FromBody] RegisterRequest request)
    {
        // 无需登录
    }

    [Authorize]  // 需要登录
    [HttpGet("list")]
    public async Task<ApiResult<PageResult<Registration>>> List([FromQuery] QueryRequest query)
    {
        // 需要登录
    }
}

// ❌ 错误：未标注授权
[ApiController]
[Route("api/[controller]")]
public class AdminController : ControllerBase  // 缺少 [Authorize]
{
    [HttpDelete("{id}")]
    public async Task<ApiResult<bool>> Delete(long id)
    {
        // 任何登录用户都能调用！
    }
}
```

##### 2. 管理接口必须使用角色鉴权

```csharp
// ✅ 正确：角色鉴权
[Authorize(Roles = "Admin")]
public class AdminController : ControllerBase { }

// ✅ 正确：策略鉴权（更灵活）
[Authorize(Policy = "RequireAdminRole")]
public class AdminController : ControllerBase { }

// ❌ 错误：仅 [Authorize] 无角色限制
[Authorize]  // 任何登录用户都能访问
public class AdminController : ControllerBase { }
```

##### 3. 公开接口必须配置速率限制

```csharp
// Program.cs
builder.Services.AddRateLimiter(options =>
{
    options.AddFixedWindowLimiter("RegistrationLimiter", opt =>
    {
        opt.PermitLimit = 5;  // 每窗口最多 5 次
        opt.Window = TimeSpan.FromMinutes(1);
        opt.QueueLimit = 0;
    });
});

// Controller
[AllowAnonymous]
[HttpPost]
[EnableRateLimiting("RegistrationLimiter")]
public async Task<ApiResult<long>> Register([FromBody] RegisterRequest request)
{
    // 每分钟最多 5 次注册
}
```

#### 检查方法

```bash
### 查找未标注授权的 Controller
grep -r "public class.*Controller" --include="*.cs" | while read line; do
  file=$(echo "$line" | cut -d: -f1)
  if ! grep -q "\[Authorize" "$file"; then
    echo "⚠️ 缺少授权: $file"
  fi
done
```

## JWT与HTTPS规范

#### JWT 密钥校验

##### 强制规则：启动时校验密钥长度

```csharp
// Program.cs
var jwtSettings = builder.Configuration.GetSection("Jwt");
var secretKey = jwtSettings["SecretKey"];

// ✅ 强制：启动时校验密钥长度
if (string.IsNullOrEmpty(secretKey) || secretKey.Length < 32)
{
    throw new InvalidOperationException(
        "JWT SecretKey 必须至少 32 字符（256 位），当前配置无效。" +
        "请在 appsettings.Production.json 中配置安全的密钥。");
}

builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,
            ValidIssuer = jwtSettings["Issuer"],
            ValidAudience = jwtSettings["Audience"],
            IssuerSigningKey = new SymmetricSecurityKey(
                Encoding.UTF8.GetBytes(secretKey))
        };
    });
```

##### 密钥生成建议

```bash
### 生成 256 位随机密钥（32 字符 Base64）
openssl rand -base64 32

### 或 64 字符十六进制
openssl rand -hex 32
```

##### 配置示例

```json
// appsettings.json（开发环境，仅用于本地调试）
{
  "Jwt": {
    "SecretKey": "dev-only-key-must-be-at-least-32-chars-long!",
    "Issuer": "hnu-waterelec",
    "Audience": "hnu-waterelec-api",
    "ExpirationMinutes": 480
  }
}

// appsettings.Production.json（生产环境）
{
  "Jwt": {
    "SecretKey": "${JWT_SECRET_KEY}",  // 从环境变量读取
    "Issuer": "hnu-waterelec",
    "Audience": "hnu-waterelec-api",
    "ExpirationMinutes": 120  // 生产环境缩短有效期
  }
}
```

#### HTTPS 强制

##### 强制规则：生产环境必须强制 HTTPS

```csharp
// Program.cs
if (!builder.Environment.IsDevelopment())
{
    // ✅ 强制 HTTPS
    app.UseHttpsRedirection();
    
    // HSTS（可选，推荐）
    app.UseHsts();
}

// 或在 Kestrel 配置中强制
builder.WebHost.ConfigureKestrel(options =>
{
    options.ConfigureHttpsDefaults(httpsOptions =>
    {
        httpsOptions.SslProtocols = System.Security.Authentication.SslProtocols.Tls12 | 
                                     System.Security.Authentication.SslProtocols.Tls13;
    });
});
```

##### 开发环境例外

```csharp
// 开发环境允许 HTTP（但应提示）
if (builder.Environment.IsDevelopment())
{
    app.UseDeveloperExceptionPage();
    // 不强制 HTTPS，方便本地调试
}
else
{
    app.UseHttpsRedirection();
    app.UseHsts();
}
```

#### 检查清单

- [ ] JWT 密钥长度 ≥ 32 字符（256 位）
- [ ] 启动时校验密钥有效性，无效则拒绝启动
- [ ] 生产环境配置 `UseHttpsRedirection()`
- [ ] 生产环境 JWT 有效期 ≤ 2 小时
- [ ] 密钥从环境变量或密钥管理服务读取，不硬编码

## 文件上传安全规范

#### 强制规则

##### 1. 文件大小限制

```csharp
// Program.cs
builder.Services.Configure<FormOptions>(options =>
{
    options.MultipartBodyLengthLimit = 10 * 1024 * 1024; // 10 MB
});

// Controller
[HttpPost("upload")]
public async Task<ApiResult<string>> Upload(IFormFile file)
{
    // ✅ 强制：校验文件大小
    const long maxFileSize = 5 * 1024 * 1024; // 5 MB
    if (file.Length > maxFileSize)
    {
        return ApiResult.Fail<string>("文件大小不能超过 5MB");
    }
    
    // 继续处理...
}
```

##### 2. 文件类型校验（MIME + 扩展名双重校验）

```csharp
// 允许的 MIME 类型
private static readonly HashSet<string> AllowedMimeTypes = new()
{
    "image/jpeg",
    "image/png",
    "image/gif",
    "application/pdf"
};

// 允许的扩展名
private static readonly HashSet<string> AllowedExtensions = new(StringComparer.OrdinalIgnoreCase)
{
    ".jpg", ".jpeg", ".png", ".gif", ".pdf"
};

[HttpPost("upload")]
public async Task<ApiResult<string>> Upload(IFormFile file)
{
    // ✅ 强制：MIME 类型校验
    if (!AllowedMimeTypes.Contains(file.ContentType))
    {
        return ApiResult.Fail<string>($"不支持的文件类型: {file.ContentType}");
    }
    
    // ✅ 强制：扩展名校验
    var extension = Path.GetExtension(file.FileName);
    if (!AllowedExtensions.Contains(extension))
    {
        return ApiResult.Fail<string>($"不支持的文件扩展名: {extension}");
    }
    
    // ✅ 推荐：读取文件头校验魔数（防止伪造扩展名）
    using var stream = file.OpenReadStream();
    var header = new byte[8];
    await stream.ReadAsync(header);
    
    if (!IsValidFileHeader(header, extension))
    {
        return ApiResult.Fail<string>("文件内容与扩展名不匹配");
    }
    
    // 继续处理...
}

private bool IsValidFileHeader(byte[] header, string extension)
{
    return extension.ToLower() switch
    {
        ".jpg" or ".jpeg" => header[0] == 0xFF && header[1] == 0xD8,
        ".png" => header[0] == 0x89 && header[1] == 0x50,
        ".gif" => header[0] == 0x47 && header[1] == 0x49,
        ".pdf" => header[0] == 0x25 && header[1] == 0x50,
        _ => false
    };
}
```

##### 3. 文件存储安全

```csharp
// ✅ 正确：使用随机文件名，不保留原始文件名
var fileName = $"{Guid.NewGuid()}{extension}";
var filePath = Path.Combine(uploadPath, fileName);

using (var stream = new FileStream(filePath, FileMode.Create))
{
    await file.CopyToAsync(stream);
}

// ❌ 错误：直接使用用户上传的文件名
var filePath = Path.Combine(uploadPath, file.FileName); // 可能包含路径穿越攻击
```

##### 4. 前端上传规范

```typescript
// ✅ 正确：让浏览器自动设置 Content-Type（multipart/form-data + boundary）
async function uploadFile(file: File) {
  const formData = new FormData()
  formData.append('file', file)
  
  // ❌ 禁止：手动设置 Content-Type
  // const res = await axios.post('/api/upload', formData, {
  //   headers: { 'Content-Type': 'multipart/form-data' }  // 错误！
  // })
  
  // ✅ 正确：不设置 Content-Type，让浏览器自动处理
  const res = await axios.post('/api/upload', formData)
  return res.data
}

// ✅ 强制：前端也做大小校验
const MAX_FILE_SIZE = 5 * 1024 * 1024 // 5 MB

function validateFile(file: File): string | null {
  if (file.size > MAX_FILE_SIZE) {
    return `文件大小不能超过 5MB`
  }
  
  const allowedTypes = ['image/jpeg', 'image/png', 'image/gif', 'application/pdf']
  if (!allowedTypes.includes(file.type)) {
    return `不支持的文件类型: ${file.type}`
  }
  
  return null
}
```

#### 完整示例

```csharp
[HttpPost("upload")]
[RequestSizeLimit(10 * 1024 * 1024)] // 整个请求最大 10MB
public async Task<ApiResult<string>> Upload(IFormFile file)
{
    // 1. 校验文件大小
    const long maxFileSize = 5 * 1024 * 1024;
    if (file.Length > maxFileSize)
    {
        return ApiResult.Fail<string>("文件大小不能超过 5MB");
    }
    
    // 2. 校验 MIME 类型
    var allowedMimeTypes = new[] { "image/jpeg", "image/png", "application/pdf" };
    if (!allowedMimeTypes.Contains(file.ContentType))
    {
        return ApiResult.Fail<string>($"不支持的文件类型: {file.ContentType}");
    }
    
    // 3. 校验扩展名
    var extension = Path.GetExtension(file.FileName);
    var allowedExtensions = new[] { ".jpg", ".jpeg", ".png", ".pdf" };
    if (!allowedExtensions.Contains(extension.ToLower()))
    {
        return ApiResult.Fail<string>($"不支持的文件扩展名: {extension}");
    }
    
    // 4. 生成安全文件名
    var fileName = $"{Guid.NewGuid()}{extension}";
    var filePath = Path.Combine(_uploadPath, fileName);
    
    // 5. 保存文件
    using (var stream = new FileStream(filePath, FileMode.Create))
    {
        await file.CopyToAsync(stream);
    }
    
    return ApiResult.Ok(fileName);
}
```

#### 检查清单

- [ ] 后端校验文件大小（≤ 10MB）
- [ ] 后端校验 MIME 类型（白名单）
- [ ] 后端校验文件扩展名（白名单）
- [ ] 使用随机文件名，不保留原始文件名
- [ ] 前端也做大小和类型校验（提升用户体验）
- [ ] 前端不手动设置 `Content-Type: multipart/form-data`

## 多租户数据隔离规范

#### 强制规则

##### 1. 所有查询必须带租户过滤

```csharp
// ❌ 错误：未过滤租户
public async Task<List<Registration>> GetAll()
{
    return await _db.Queryable<Registration>().ToListAsync();
    // 会返回所有租户的数据！
}

// ✅ 正确：显式过滤租户
public async Task<List<Registration>> GetAll(long tenantId)
{
    return await _db.Queryable<Registration>()
        .Where(r => r.TenantId == tenantId)
        .ToListAsync();
}

// ✅ 更好：使用全局过滤器（SqlSugar）
public class Registration : ITenantEntity
{
    public long Id { get; set; }
    public long TenantId { get; set; }  // 必须字段
    // ...
}

// 配置全局过滤器
_db.QueryFilter.AddTableFilter<ITenantEntity>(it => 
    it.TenantId == _currentTenantId);
```

##### 2. 租户 ID 必须从认证信息获取

```csharp
// ❌ 错误：从请求参数获取租户 ID
[HttpGet]
public async Task<ApiResult<List<Registration>>> List([FromQuery] long tenantId)
{
    var data = await _service.GetAll(tenantId);  // 用户可伪造 tenantId！
    return ApiResult.Ok(data);
}

// ✅ 正确：从 JWT Claim 获取租户 ID
[HttpGet]
public async Task<ApiResult<List<Registration>>> List()
{
    var tenantId = GetCurrentTenantId();  // 从 Claims 获取
    var data = await _service.GetAll(tenantId);
    return ApiResult.Ok(data);
}

private long GetCurrentTenantId()
{
    var claim = User.FindFirst("TenantId");
    if (claim == null)
    {
        throw new BusinessException("用户未绑定租户", 403);
    }
    return long.Parse(claim.Value);
}
```

##### 3. 实体必须实现租户接口

```csharp
// 定义租户接口
public interface ITenantEntity
{
    long TenantId { get; set; }
}

// 所有业务实体必须实现
public class Registration : ITenantEntity
{
    public long Id { get; set; }
    public long TenantId { get; set; }  // 必须字段
    public string Name { get; set; }
    // ...
}

public class CompanyInfo : ITenantEntity
{
    public long Id { get; set; }
    public long TenantId { get; set; }  // 必须字段
    public string CompanyName { get; set; }
    // ...
}
```

##### 4. 数据库迁移必须添加租户字段

```sql
-- ✅ 正确：所有业务表必须有 TenantId
CREATE TABLE Registration (
    Id BIGINT PRIMARY KEY,
    TenantId BIGINT NOT NULL,  -- 必须字段
    Name NVARCHAR(100) NOT NULL,
    -- ...
    INDEX IX_Registration_TenantId (TenantId)  -- 必须索引
);

-- 外键约束
ALTER TABLE Registration
ADD CONSTRAINT FK_Registration_Tenant
FOREIGN KEY (TenantId) REFERENCES Tenant(Id);
```

#### 检查清单

- [ ] 所有业务实体实现 `ITenantEntity` 接口
- [ ] 所有查询带租户过滤（推荐全局过滤器）
- [ ] 租户 ID 从 JWT Claim 获取，不从请求参数获取
- [ ] 数据库表包含 `TenantId` 字段和索引
- [ ] 单元测试验证租户隔离（A 租户不能访问 B 租户数据）
