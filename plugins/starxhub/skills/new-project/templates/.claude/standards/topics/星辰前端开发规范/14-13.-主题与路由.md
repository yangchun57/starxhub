# 星辰前端开发规范 · 13. 主题与路由

> 拆分自《星辰前端开发规范》第 14 节。需要全量上下文时读原文件。


### 13.1 主题切换（MUST）

```ts
document.documentElement.dataset.theme = 'dark'   // 'light' | 'dark'
localStorage.setItem('hx-theme', theme)           // key 固定为 hx-theme
```

`useTheme.ts` 在模块加载时立即 `apply()` 一次，避免首屏闪白；返回 `{ theme, toggle, set }`。Dark 只覆盖 23 个表面 / 文本 / 柔和底令牌，语义色与尺寸不变。

### 13.2 路由（MUST）

- `createWebHashHistory()`：无需服务端 rewrite，`dist/` 直接放进 .NET8 `wwwroot` 任意子目录即可（`base: './'`）。
- `NAV_ITEMS` 是**导航、面包屑、路由三者的共同配置源**；每项含 `key / label / path / icon`，可选 `group / badge`。
- 每个路由必须带 `meta.title` 与 `meta.crumb`；未匹配路径统一 `redirect: '/dashboard'`。
- 新增页面 5 步：在 `views/` 下新建视图组件 → 追加 `NAV_ITEMS` → 追加 `routes`（含 meta）→ 用 §11.2 模板搭区块 → `npm run build` + `npm run sync:showcase`。
