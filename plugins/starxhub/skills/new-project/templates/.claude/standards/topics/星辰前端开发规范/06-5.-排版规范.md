# 星辰前端开发规范 · 5. 排版规范

> 拆分自《星辰前端开发规范》第 6 节。需要全量上下文时读原文件。


| 规则 | 要求 | 等级 |
| --- | --- | --- |
| 全局字号 | `body` 使用 `--hx-fs-body`（12px），`line-height: 1.5` | MUST |
| 标题层级 | 页面标题用 `.hx-page-title`；卡片标题用 `.hx-card-title`；区块标题用 `.hx-section-title`（带 3px 品牌竖条） | MUST |
| 数字 | 金额、编号、百分比、日期一律 `.hx-num` 或 `.hx-metric` | MUST |
| 货币 | `¥` + 千分位，如 `¥ 486,320`；数值右对齐时加 `.hx-strong-cell` | SHOULD |
| 溢出 | 单行文本用 `white-space: nowrap` + `text-overflow: ellipsis`；表格行不折行，容器横向滚动 | MUST |
| 代码 / 目录树 | `pre.hx-code` 保持 `white-space: pre`、不折行、横向滚动、禁用连字 | MUST |
| 字重 | 标题 700、卡片标题 600、按钮 600、正文 400、表头 500 | SHOULD |
