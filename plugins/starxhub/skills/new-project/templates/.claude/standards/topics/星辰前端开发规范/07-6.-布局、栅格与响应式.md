# 星辰前端开发规范 · 6. 布局、栅格与响应式

> 拆分自《星辰前端开发规范》第 7 节。需要全量上下文时读原文件。


### 6.1 骨架尺寸（1440 × 900 基准）

```
┌──────────────┬──────────────────────────────────────┐
│ 侧栏 236px   │ 顶栏 72px                            │
│ 品牌 80px    ├──────────────────────────────────────┤
│ 导航（滚动） │ .hx-content padding 24px / gap 18px   │
│ 底部卡+用户  │ 栅格：KPI 自适应 / 主区 1fr + 360px   │
└──────────────┴──────────────────────────────────────┘
```

### 6.2 栅格类

| 类 | 定义 | 用途 |
| --- | --- | --- |
| `.hx-grid-kpi` | `repeat(auto-fit, minmax(220px, 1fr))`，gap 16px | KPI 行 |
| `.hx-grid-main` | `minmax(0, 1fr) 360px`，gap 18px | 主内容 + 侧栏卡片 |
| `.hx-grid-2` / `.hx-grid-3` | 2 / 3 等分，gap 18px | 表单、普通卡片组 |
| `.hx-row` / `.hx-row-between` / `.hx-col` / `.hx-spacer` | flex 行 / 两端对齐 / 列 / 弹性占位 | 局部排布 |

### 6.3 断点表（MUST）

| 断点 | 生效规则 |
| --- | --- |
| `≤1180px` | `.hx-grid-main` 变单列；`.hx-grid-3` 变 2 列 |
| `≤860px` | `--hx-sidebar-w` 改为 `68px`；内容区 padding 16px；`.hx-grid-2` / `.hx-grid-3` 单列；`.hx-hide-narrow` 元素隐藏（文字、品牌名、搜索框、辅助卡） |
| `≤560px` | `.hx-grid-kpi` 固定 2 列；`.hx-select-spec-panel` 占满宽 |
| `≤760px`（高度） | 侧栏辅助卡隐藏，导航优先获得高度 |
| `≤480px`（高度） | 品牌区由 80px 压到 60px，保证至少 3 个导航项可见 |

> 窄屏侧栏收窄后只留图标，因此所有 `hx-hide-narrow` 内容必须同时有 `title` / `aria-label` 之类的可访问替代（见 §15）。
