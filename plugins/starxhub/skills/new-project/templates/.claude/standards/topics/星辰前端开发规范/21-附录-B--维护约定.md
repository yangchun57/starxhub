# 星辰前端开发规范 · 附录 B · 维护约定

> 拆分自《星辰前端开发规范》第 21 节。需要全量上下文时读原文件。


1. 改令牌 / 组件样式 → 改 `src/styles/*.css` → `npm run sync:showcase` → 更新本文 §3 / §9 / 附录 A。
2. 改组件 Props → 同步本文 §9 表格与 `showcase/app.js` 的静态展示，避免文档与预览两张皮。
3. 新增页面 / 路由 → 走 §13.2 五步，并在 §11.1 补一行。
4. 本文不记录临时路径、构建日志与一次性调试结论；踩坑只保留「现象 / 根因 / 规范条款」三列。
5. 任何与本文冲突的实现，先改代码再改文档，或先改文档再排期改代码 —— **不允许长期不一致**。
