# 星辰前端开发规范 · 8. 动效规范

> 拆分自《星辰前端开发规范》第 9 节。需要全量上下文时读原文件。


| 项 | 值 | 说明 |
| --- | --- | --- |
| 常规过渡 | `var(--hx-dur)` = `160ms` + `var(--hx-ease)` | 背景、边框、颜色、transform |
| 页面进入 | `.hx-fade-in`：`220ms`，`translateY(6px) → 0` | 挂在 `<router-view>` 的组件上 |
| 下拉展开 | `hx-select-pop`：`160ms`，`opacity 0 + translateY(-4px) scale(0.985) → 1`；向上翻转时 `transform-origin: bottom center` | 见 §9.3 |
| 进度条 | `320ms` width 过渡 | `.hx-progress-fill` |
| 骨架屏 | `hx-shimmer` `1.3s infinite linear` | 加载态 |
| 按钮按压 | `transform: translateY(1px)` | `.hx-btn:active` |
| 降级 | `@media (prefers-reduced-motion: reduce)` 下所有动画 / 过渡降到 `0.01ms` | MUST |

> 自动化截图验证时，若动画导致 `opacity: 0`，需注入 `animation: none` 后再断言（这是验证手段，不要因此移除动画）。
