# 星辰前端开发规范 · 16. 交付与验证清单

> 拆分自《星辰前端开发规范》第 17 节。需要全量上下文时读原文件。


### 16.1 命令

```bash
npm run typecheck        # vue-tsc --noEmit
npm run build            # vue-tsc --noEmit && vite build（基线：94 modules / CSS ~22KB / JS ~116KB）
npm run dev              # http://localhost:5173
npm run sync:showcase    # 改过 src/styles/*.css 后必须执行
```

### 16.2 发布前逐项打勾

- [ ] `npm run build` 无报错；`dist/` 以相对路径引用资源（`base: './'`）。
- [ ] 1440×900 与 860px 窄屏下：侧栏固定、顶栏固定、**只有内容区滚动**，导航可滚到末项。
- [ ] `#/pages` 目录卡片完整可见且能滚到最底部（`scrollHeight > clientHeight` 且 `scrollTop` 可达底部）；ASCII 目录树横向可滚、不折行。
- [ ] 所有下拉：`parent = BODY`、`position = fixed`、`z-index = 200`、`opacity = 1`、选项数与选中数正确；DOM 中**无原生 `<select>`** 残留。
- [ ] 浅色选中项底色 `rgb(245, 248, 255)`（`--hx-brand-wash`），暗色 `rgb(27, 44, 73)`。
- [ ] 暗色模式：卡片、表格、浮层、滚动条无刺眼白条；横幅渐变切换到暗色版本。
- [ ] 键盘全链路：Tab → 下拉 → ↑↓ → Enter → Esc；弹窗遮罩点击关闭。
- [ ] 9 个路由逐一打开无空白；`#/components`、`#/tokens`、`#/pages`、`#/dashboard`、`#/orders` 5 个静态预览页无 JS 异常。
- [ ] 本文 §3 令牌表与 `tokens.css` 一致（改过令牌则同步更新）。
