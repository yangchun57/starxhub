# 星辰前端开发规范 · 14. 扩展与替换边界

> 拆分自《星辰前端开发规范》第 15 节。需要全量上下文时读原文件。


| 想替换 | 允许做法 | 禁止做法 |
| --- | --- | --- |
| 基础控件 → Element Plus / Naive UI | 保留 `tokens.css` + `common.css`；重写 `base/` 组件为薄适配层，保持组件名 / Props / `defineModel` 不变；把库主题变量映射到 `--hx-*` | 删除 `.hx-app` / `.hx-content` 滚动规则；在页面里直接写库组件类名 |
| 图表 → ECharts | 只替换 `charts/` 3 个组件；颜色取 `--hx-chart-1..4`；容器沿用 `.hx-chart` | 在视图里直接 `echarts.init` |
| 图标 → 图标库 | 只改 `assets/icons.ts` 的 `icon()` 实现，保持 `name` 映射与 18×18 契约 | 改变 `stroke="currentColor"` 约定 |
| 状态管理 → Pinia | 新增 `stores/`，通过 `useRequest` 取数后写入 store | 让组件直接 `fetch` |
| 新增业务状态 | 在 `StatusTag.vue` 的 `MAP` 补映射，必要时扩 `OrderStatus` / `Tone` | 在页面里内联判断颜色 |

**不变量（任何替换都不得破坏）**：三层 CSS 加载顺序、`hx-` 类名前缀、69 个令牌名、`.hx-app` / `.hx-nav` / `.hx-content` 滚动模型、`ApiResult<T>` 契约、hash 路由与 `base: './'`。
