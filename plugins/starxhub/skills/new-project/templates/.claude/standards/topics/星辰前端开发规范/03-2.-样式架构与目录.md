# 星辰前端开发规范 · 2. 样式架构与目录

> 拆分自《星辰前端开发规范》第 3 节。需要全量上下文时读原文件。


### 2.1 加载顺序（MUST，不可调换）

```html
<link rel="stylesheet" href="/src/styles/tokens.css" />      <!-- 1. 变量 -->
<link rel="stylesheet" href="/src/styles/common.css" />      <!-- 2. reset / 骨架 / 栅格 / 工具类 -->
<link rel="stylesheet" href="/src/styles/components.css" />  <!-- 3. 组件外观 -->
```

静态预览页 `showcase/index.html` 使用同目录 `./tokens.css`、`./common.css`、`./components.css`，由 `npm run sync:showcase`（`showcase/sync-styles.mjs`）从 `src/styles` 复制而来。原因：静态预览服务不允许 HTML 跨上级目录取资源（403）。

### 2.2 目录结构

```
hexu-admin/
├── index.html                 # 入口，仅做三份 CSS + main.ts 挂载
├── vite.config.ts             # base:'./'、@ 别名、/api 代理
├── src/
│   ├── main.ts / App.vue
│   ├── styles/                # ★ 样式唯一事实来源
│   │   ├── tokens.css
│   │   ├── common.css
│   │   └── components.css
│   ├── router/index.ts        # NAV_ITEMS + routes（同一份配置）
│   ├── types/index.ts         # DTO / ApiResult<T> / TableColumn<T>
│   ├── mock/index.ts          # api 门面，返回 ApiResult<T>
│   ├── composables/           # useRequest.ts / useTheme.ts
│   ├── assets/icons.ts        # 18×18 线性 SVG 图标表
│   ├── components/
│   │   ├── layout/            # AppShell / AppSidebar / AppTopbar / PageHeader
│   │   ├── base/              # HxIcon / HxButton / HxInput / HxSelect / HxTag
│   │   │                     # HxCard / HxPagination / HxEmpty / HxModal
│   │   ├── biz/               # StatusTag / FilterBar / DataTable / StatCard / TodoItem
│   │   └── charts/            # Sparkline / HxLineChart / HxDonutChart
│   └── views/                 # 9 个页面（见 §11.1）
├── showcase/                  # 零依赖静态预览（可直接在浏览器打开）
│   ├── index.html / app.js / sync-styles.mjs
│   └── tokens.css / common.css / components.css   # 生成物，勿手改
└── docs/DESIGN_SPEC.md        # 本文
```

### 2.3 命名规则（MUST）

| 对象 | 规则 | 示例 |
| --- | --- | --- |
| CSS 类 | `hx-` 前缀 + 短横线；变体用 `--`，状态用 `is-` | `.hx-btn--primary`、`.hx-nav-item.is-active` |
| 变量 | `--hx-<类别>-<语义>` | `--hx-brand-soft`、`--hx-radius-card` |
| 组件文件 | `Hx` 前缀或 `App` 前缀，PascalCase `.vue` | `HxSelect.vue`、`AppSidebar.vue` |
| 视图文件 | `<模块>View.vue` | `OrdersView.vue` |
| 图标 key | 小写单词 / camelCase | `chevronRight`、`grid` |
| 类型 | PascalCase；联合类型用 `Tone`、`OrderStatus` | `TableColumn<T>` |
