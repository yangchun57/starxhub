# 星辰前端开发规范 · 1. 设计定位与原则

> 拆分自《星辰前端开发规范》第 2 节。需要全量上下文时读原文件。


### 1.1 定位

面向内部运营后台（订单 / 商品 / 客户 / 营销 / 消息 / 设置），视觉基调为「**活泼但不轻浮、正式但不沉闷**」：深色导航压住整体气场，浅色工作区保证长时间阅读舒适，电光蓝作为唯一强调色，彩色图标块与低饱和渐变横幅提供活力。

### 1.2 六条原则

| # | 原则 | 落地方式 | 等级 |
| --- | --- | --- | --- |
| P1 | 令牌驱动 | 颜色 / 圆角 / 间距 / 字号 / 动效全部来自 `tokens.css` | MUST |
| P2 | 单一事实来源 | Vue 工程与 `showcase/` 静态页引用同一份 CSS，静态页副本由脚本生成、禁止手改 | MUST |
| P3 | 结构与外观分离 | SFC 只负责 DOM 与状态，外观靠 `hx-` 类名；不在组件内写样式 | MUST |
| P4 | 语义优先 | 状态色表达业务含义（成功 / 警告 / 危险 / 信息），不用「红=坏、绿=好」的裸色值 | MUST |
| P5 | 可替换 | `base/` 与 `charts/` 是可插拔适配层，业务视图只依赖组件名与 Props | SHOULD |
| P6 | 无障碍基线 | 可聚焦、可键盘操作、暗色可读、尊重 `prefers-reduced-motion` | SHOULD |

> **金额 / 涨跌补充约定**：本框架是运营后台，`--hx-success` / `--hx-danger` 表达业务成败，不表示行情涨跌。若后续接入股票 / 行情模块，须按 A 股惯例改用「涨红跌绿」并单独定义令牌，不得直接复用本套语义色。
