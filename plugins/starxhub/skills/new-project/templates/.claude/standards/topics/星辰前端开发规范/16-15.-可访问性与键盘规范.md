# 星辰前端开发规范 · 15. 可访问性与键盘规范

> 拆分自《星辰前端开发规范》第 16 节。需要全量上下文时读原文件。


| 项 | 要求 | 等级 |
| --- | --- | --- |
| 语义标签 | 侧栏 `<aside>` + `<nav>`、顶栏 `<header>`、主区 `<main>`、卡片 `<section>` | SHOULD |
| 下拉 | 触发器 `role="combobox"` + `aria-haspopup="listbox"` + `aria-expanded`；面板 `role="listbox"`，选项 `role="option"` + `aria-selected` | MUST |
| 键盘 | `Tab` 聚焦、`↑/↓` 移动、`Enter/Space` 确认、`Esc` 关闭；`HxSelect` / `HxModal` 全部支持 | MUST |
| 焦点可见 | 输入框 / 下拉触发器 `.is-open` 用 `--hx-brand` 边框 + 3px 焦点环 | MUST |
| 装饰 SVG | `aria-hidden="true"`；纯图标按钮带 `title` | SHOULD |
| 色彩 | 状态不只靠颜色区分，必须带文字（标签文案 / 提示文案） | MUST |
| 动效 | 尊重 `prefers-reduced-motion: reduce` | MUST |
