### 设计稿维护侧（Ardot 操作备忘）

- `U()` 改不了 SVG 内容，需删掉重插；`C()` 复制普通帧时 descendants 可能失效，需 `batch_read` 查新 ID 后逐行更新。
- 大号数字 / 标题不要用单个 SVG 文本节点，Ardot 限宽会把文字挤成竖排，改用真实 text / frame 节点。
- Ardot 设计稿变量集（创建时命名，工程侧统一为「星辰（starTech）」）Light 14 个变量 → 工程 69 个令牌的映射见 §18.1；**不要为改名而重建变量集**，会断开已绑定的变量引用。
