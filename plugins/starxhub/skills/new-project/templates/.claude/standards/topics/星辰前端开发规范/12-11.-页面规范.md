# 星辰前端开发规范 · 11. 页面规范

> 拆分自《星辰前端开发规范》第 12 节。需要全量上下文时读原文件。


### 11.1 九个内置页面

| 路由 | 视图 | 页面类型 |
| --- | --- | --- |
| `#/dashboard` | `DashboardView.vue` | 工作台（横幅 + KPI + 趋势/来源 + 列表/动态） |
| `#/analytics` | `AnalyticsView.vue` | 数据看板 |
| `#/orders` | `OrdersView.vue` | 列表页（统计卡 + 筛选 + 表格 + 分页 + 弹窗） |
| `#/products` | `ProductsView.vue` | 列表页 |
| `#/customers` | `CustomersView.vue` | 列表页 |
| `#/marketing` | `MarketingView.vue` | 列表页 |
| `#/messages` | `MessagesView.vue` | 消息 / 时间线 |
| `#/settings` | `SettingsView.vue` | 表单设置（开关 / 分段 / 表单栅格） |
| `#/components` | `ComponentsView.vue` | 组件库规范说明 |

### 11.2 四类页面模板（MUST 遵循区块顺序）

| 类型 | 区块顺序 |
| --- | --- |
| 工作台 | `.hx-banner` → `.hx-grid-kpi`（StatCard）→ `.hx-grid-main`（图表卡 + 来源卡）→ `.hx-grid-main`（列表卡 + 动态卡） |
| 列表页 | `PageHeader`（含 actions）→ `.hx-grid-kpi` 紧凑统计 → `FilterBar` → `HxCard`（表头 + 分割线 + `DataTable` + 分割线 + `.hx-table-foot`/`HxPagination`）→ 可选 `HxModal` |
| 表单页 | `PageHeader` → `HxCard` → `.hx-form-grid`（两列 `.hx-field`）→ 底部操作区（右对齐） |
| 设置 / 说明页 | `PageHeader` → `.hx-section-title` 分区 → `HxCard` / `.hx-demo` / `.hx-spec` 表格 / `pre.hx-code` |

页面根节点统一 `<div class="hx-col" style="gap: var(--hx-gap-section)">`，不要另设 padding（由 `.hx-content` 统一给 24px）。

### 11.3 状态覆盖（SHOULD）

每个数据页至少处理：加载中（`.hx-skeleton` 占位）、空数据（`HxEmpty`）、失败（`useRequest().error` → `.hx-alert--danger`）、正常。危险操作二次确认用 `HxModal` + `@confirm`。
