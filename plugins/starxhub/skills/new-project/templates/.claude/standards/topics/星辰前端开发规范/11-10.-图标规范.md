# 星辰前端开发规范 · 10. 图标规范

> 拆分自《星辰前端开发规范》第 11 节。需要全量上下文时读原文件。


- 资源：`src/assets/icons.ts` 的 `ICONS` 表，共 33 个 18×18 线性图标；`icon(name)` 返回 SVG 字符串，未知 key 回退 `grid`。
- 统一 `fill="none"`、`stroke="currentColor"`、`stroke-width="1.5"`、圆角线帽 / 线连接；**颜色由父级 `color` 决定**，选中态无需换资源。
- 尺寸映射：导航 18px（`.hx-nav-icon`）、按钮前置 14px、输入前缀 16px（`.hx-input-icon`）、下拉箭头 12px、勾选 14px、空态 56px。
- 禁止 emoji 充当图标（PPT / 设计稿同理用图标字体或 SVG）。生产可整体替换为 `lucide-vue-next` / `@element-plus/icons-vue`，保持 `icon(name)` 门面不变即可。
