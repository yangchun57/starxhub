# 并发与资源管理规范

> 单一事实来源：本文件由历史 topics 手工分片回并生成，章节标题与分片文件名一一对应。
> `topics/` 由 `split-standards.py` 按 `## ` 重建，禁止手改分片；分片正文标题已整体降两级，避免被误切。

## 概述

#### 适用范围

本规范适用于所有涉及数据库连接、异步操作、并发更新、资源导出的代码。

#### 核心原则

1. **资源生命周期原则**：DI 注册的生命周期必须与资源特性匹配
2. **协作取消原则**：所有异步操作必须支持 CancellationToken
3. **并发安全原则**：共享资源的更新必须有并发控制
4. **内存可控原则**：大数据量处理必须使用流式传输，避免内存溢出

#### 问题分类

| 级别 | 说明 | 示例 |
|------|------|------|
| Critical | 导致数据损坏或系统崩溃 | DI 生命周期错误、无并发控制 |
| High | 导致资源泄漏或性能问题 | 缺少 CancellationToken、内存溢出 |
| Medium | 潜在风险但影响较小 | 查询逻辑重复 |

#### 强制检查清单

- [ ] SqlSugarScope 是否注册为 Singleton
- [ ] Async 方法是否传递 CancellationToken
- [ ] 并发更新是否使用乐观锁或悲观锁
- [ ] 大数据导出是否使用流式传输
- [ ] 唯一性约束是否在数据库层面保证

## DI生命周期规范

#### 强制规则

##### 1. SqlSugarScope 必须注册为 Singleton

```csharp
// ❌ 错误：注册为 Scoped 或 Transient
builder.Services.AddScoped<ISqlSugarClient>(provider =>
{
    var scope = new SqlSugarScope(new ConnectionConfig
    {
        ConnectionString = connectionString,
        DbType = DbType.SqlServer,
        IsAutoCloseConnection = true
    });
    return scope;
});

// ✅ 正确：注册为 Singleton
builder.Services.AddSingleton<ISqlSugarClient>(provider =>
{
    var scope = new SqlSugarScope(new ConnectionConfig
    {
        ConnectionString = connectionString,
        DbType = DbType.SqlServer,
        IsAutoCloseConnection = true
    });
    
    // 可选：配置 AOP
    scope.Aop.OnLogExecuting = (sql, pars) =>
    {
        Console.WriteLine(sql);
    };
    
    return scope;
});
```

##### 2. 理解 SqlSugarScope 的线程安全性

```csharp
// SqlSugarScope 是线程安全的，内部维护连接池
// 每个线程获取独立的连接，无需担心并发问题

// ✅ 正确：在 Service 中注入使用
public class RegistrationService : IRegistrationService
{
    private readonly ISqlSugarClient _db;
    
    public RegistrationService(ISqlSugarClient db)
    {
        _db = db;  // Singleton 注入到 Scoped Service 是安全的
    }
    
    public async Task<List<Registration>> GetAll()
    {
        return await _db.Queryable<Registration>().ToListAsync();
    }
}

// ❌ 错误：每次 new SqlSugarClient
public class RegistrationService
{
    public async Task<List<Registration>> GetAll()
    {
        using var db = new SqlSugarClient(new ConnectionConfig
        {
            ConnectionString = "...",
            DbType = DbType.SqlServer
        });
        return await db.Queryable<Registration>().ToListAsync();
    }
}
```

##### 3. 其他 ORM 的生命周期建议

```csharp
// Entity Framework Core
builder.Services.AddDbContext<AppDbContext>(options =>
{
    options.UseSqlServer(connectionString);
}, ServiceLifetime.Scoped);  // DbContext 必须是 Scoped

// Dapper（无状态，可 Singleton）
builder.Services.AddSingleton<IDbConnection>(provider =>
{
    return new SqlConnection(connectionString);
});
```

#### 检查清单

- [ ] SqlSugarScope 注册为 Singleton
- [ ] EF Core DbContext 注册为 Scoped
- [ ] 不在业务代码中直接 new ORM 客户端
- [ ] 理解 ORM 客户端的线程安全性

## CancellationToken规范

#### 强制规则

##### 1. 所有 Async 方法必须传递 CancellationToken

```csharp
// ❌ 错误：缺少 CancellationToken
public interface IRegistrationService
{
    Task<List<Registration>> GetAll();
    Task<Registration> GetById(long id);
    Task<long> Create(Registration entity);
    Task<bool> Update(Registration entity);
    Task<bool> Delete(long id);
}

// ✅ 正确：所有方法传递 CancellationToken
public interface IRegistrationService
{
    Task<List<Registration>> GetAll(CancellationToken cancellationToken = default);
    Task<Registration?> GetById(long id, CancellationToken cancellationToken = default);
    Task<long> Create(Registration entity, CancellationToken cancellationToken = default);
    Task<bool> Update(Registration entity, CancellationToken cancellationToken = default);
    Task<bool> Delete(long id, CancellationToken cancellationToken = default);
}
```

##### 2. Service 实现必须传递 CancellationToken

```csharp
public class RegistrationService : IRegistrationService
{
    private readonly ISqlSugarClient _db;
    
    public RegistrationService(ISqlSugarClient db)
    {
        _db = db;
    }
    
    // ✅ 正确：传递到 ORM 查询
    public async Task<List<Registration>> GetAll(CancellationToken cancellationToken = default)
    {
        return await _db.Queryable<Registration>()
            .ToListAsync(cancellationToken);
    }
    
    public async Task<Registration?> GetById(long id, CancellationToken cancellationToken = default)
    {
        return await _db.Queryable<Registration>()
            .Where(r => r.Id == id)
            .FirstAsync(cancellationToken);
    }
    
    public async Task<long> Create(Registration entity, CancellationToken cancellationToken = default)
    {
        return await _db.Insertable(entity)
            .ExecuteReturnSnowflakeIdAsync(cancellationToken);
    }
}
```

##### 3. Controller 传递 HttpContext.RequestAborted

```csharp
[ApiController]
[Route("api/[controller]")]
public class RegistrationController : ControllerBase
{
    private readonly IRegistrationService _service;
    
    public RegistrationController(IRegistrationService service)

        _service = service;

    {

        return ApiResult.Ok(data);
    }
    
    [HttpPost]
    public async Task<ApiResult<long>> Create([FromBody] CreateRequest request)
    {
        var entity = new Registration
        {
            Name = request.Name,
            Phone = request.Phone
        };
        
        var id = await _service.Create(entity, HttpContext.RequestAborted);
        return ApiResult.Ok(id);
    }
}
```

## 并发控制规范

#### 强制规则

##### 1. 数据库层面保证唯一性

```sql
-- ✅ 正确：数据库唯一约束
CREATE TABLE Registration (
    Id BIGINT PRIMARY KEY,
    TenantId BIGINT NOT NULL,
    Phone NVARCHAR(20) NOT NULL,
    Name NVARCHAR(100) NOT NULL,
    -- ...
    CONSTRAINT UQ_Registration_Tenant_Phone UNIQUE (TenantId, Phone)
);

-- 索引
CREATE UNIQUE INDEX IX_Registration_Tenant_Phone
ON Registration (TenantId, Phone);
```

```csharp
// Service 层捕获唯一约束异常
public async Task<long> Create(Registration entity, CancellationToken cancellationToken = default)
{
    try
    {
        return await _db.Insertable(entity)
            .ExecuteReturnSnowflakeIdAsync(cancellationToken);
    }
    catch (SqlSugarException ex) when (ex.Message.Contains("UNIQUE") || ex.ErrorCode == 2627)
    {
        throw new BusinessException($"手机号 {entity.Phone} 已存在", 409);
    }
}
```

##### 2. 乐观锁（推荐：适合低冲突场景）

```csharp
// 实体添加 RowVersion 字段
public class CompanyInfo : ITenantEntity
{
    public long Id { get; set; }
    public string CompanyName { get; set; }
    public string LogoUrl { get; set; }
    
    // ✅ 乐观锁字段
    [SugarColumn(IsOnlyIgnoreInsert = true, IsOnlyIgnoreUpdate = false)]
    public byte[] RowVersion { get; set; }
}

// SQL Server 表结构
/*
CREATE TABLE CompanyInfo (
    Id BIGINT PRIMARY KEY,
    TenantId BIGINT NOT NULL,
    CompanyName NVARCHAR(200) NOT NULL,
    LogoUrl NVARCHAR(500),
    RowVersion ROWVERSION NOT NULL  -- 自动递增
);
*/

// Service 更新方法
public async Task<bool> Update(CompanyInfo entity, CancellationToken cancellationToken = default)
{
    var result = await _db.Updateable(entity)
        .WhereColumns(it => new { it.Id, it.RowVersion })  // 包含 RowVersion
        .ExecuteCommandAsync(cancellationToken);
    
    if (result == 0)
    {
        throw new BusinessException("数据已被其他用户修改，请刷新后重试", 409);
    }
    
    return true;
}
```

##### 3. 悲观锁（适合高冲突场景）

```csharp
// 使用数据库事务 + SELECT FOR UPDATE
public async Task<bool> UpdateWithLock(long id, Action<CompanyInfo> updateAction, 
    CancellationToken cancellationToken = default)
{
    try
    {
        _db.Ado.BeginTran();
        
        // 悲观锁：SELECT FOR UPDATE
        var entity = await _db.Queryable<CompanyInfo>()
            .Where(c => c.Id == id)
            .With(SqlWith.UpdLock)  // SqlSugar 的悲观锁语法
            .FirstAsync(cancellationToken);
        
        if (entity == null)
        {
            throw new NotFoundException("企业信息", id);
        }
        
        updateAction(entity);
        
        await _db.Updateable(entity).ExecuteCommandAsync(cancellationToken);
        _db.Ado.CommitTran();
        return true;
    }
    catch
    {
        _db.Ado.RollbackTran();
        throw;
    }
}
```

- [ ] 唯一性字段在数据库层面添加唯一约束
- [ ] 并发更新使用乐观锁（RowVersion）或悲观锁
- [ ] Service 层捕获唯一约束异常并返回友好提示

## 流式导出规范

#### 强制规则

##### 1. 大数据量导出必须使用流式传输

```csharp
// ❌ 错误：一次性加载所有数据到内存
[HttpGet("export")]
public async Task<IActionResult> Export()
{
    var allData = await _db.Queryable<Registration>().ToListAsync();  // 内存溢出！
    var bytes = ExcelHelper.Export(allData);
    return File(bytes, "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet", "export.xlsx");
}

// ✅ 正确：流式查询 + 流式写入
[HttpGet("export")]
public async Task<IActionResult> Export()
{
    var stream = new MemoryStream();
    
    using (var package = new ExcelPackage())
    {
        var worksheet = package.Workbook.Worksheets.Add("Registrations");
        
        // 写入表头
        worksheet.Cells[1, 1].Value = "姓名";
        worksheet.Cells[1, 2].Value = "手机号";
        worksheet.Cells[1, 3].Value = "创建时间";
        
        int row = 2;
        const int pageSize = 1000;
        int pageIndex = 1;
        
        // ✅ 分页查询，避免内存溢出
        while (true)
        {
            var page = await _db.Queryable<Registration>()
                .OrderBy(r => r.Id)
                .ToPageListAsync(pageIndex, pageSize);
            
            if (page.Count == 0) break;
            
            foreach (var item in page)
            {
                worksheet.Cells[row, 1].Value = item.Name;
                worksheet.Cells[row, 2].Value = item.Phone;
                worksheet.Cells[row, 3].Value = item.CreatedAt;
                row++;
            }
            
            pageIndex++;
        }
        
        package.SaveAs(stream);
    }
    
    stream.Position = 0;
    return File(stream, "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet", "export.xlsx");
}
```

##### 2. 超大数据量使用 CSV 格式

```csharp
// ✅ 对于超大数据量（>10万行），推荐 CSV 格式
[HttpGet("export-csv")]
public async Task<IActionResult> ExportCsv()
{
    var stream = new MemoryStream();
    using var writer = new StreamWriter(stream, Encoding.UTF8);
    
    // 写入 BOM（Excel 识别 UTF-8）
    await writer.WriteAsync("\uFEFF");
    
    // 写入表头
    await writer.WriteLineAsync("姓名,手机号,创建时间");
    
    // 流式查询
    const int pageSize = 1000;
    int pageIndex = 1;
    
    while (true)
    {
        var page = await _db.Queryable<Registration>()
            .OrderBy(r => r.Id)
            .ToPageListAsync(pageIndex, pageSize);
        
        if (page.Count == 0) break;
        
        foreach (var item in page)
        {
            await writer.WriteLineAsync($"{item.Name},{item.Phone},{item.CreatedAt}");
        }
        
        pageIndex++;
    }
    
    await writer.FlushAsync();
    stream.Position = 0;
    
    return File(stream, "text/csv", "export.csv");
}
```

##### 3. 前端下载大文件

```typescript
// ✅ 正确：使用 Blob 下载
async function handleExport() {
  exporting.value = true
  try {
    const res = await axios.get('/api/registrations/export', {
      responseType: 'blob'  // 必须设置
    })
    
    const blob = new Blob([res.data], {
      type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'
    })
    
    const url = window.URL.createObjectURL(blob)
    const link = document.createElement('a')
    link.href = url
    link.download = `导出_${new Date().toLocaleDateString()}.xlsx`
    link.click()
    
    window.URL.revokeObjectURL(url)
    ElMessage.success('导出成功')
  } catch (error) {
    ElMessage.error('导出失败')
  } finally {
    exporting.value = false
  }
}
```
