# 交付自检清单（output-checklist）

交付前逐项打勾。A–B 为硬性技术项（任一不过必须修复），C–F 为设计质量项。

## A. 技术完整性

- [ ] `node --check hifi.js` 通过
- [ ] 目录自包含：`index.html + hifi.css + hifi.js`，**无 CDN / 外链图片 / 网络字体**，断网双击可看
- [ ] 每个 `<section class="page">` 有唯一 `id` + `data-pid` + `data-title`；舞台指示器随跳转更新
- [ ] 所有 `data-goto` 的目标 id 真实存在（逐个核对，无死链）
- [ ] 每个 `data-modal-open / data-drawer-open / data-sheet-open / data-menu-open` 的目标元素存在且 id 唯一
- [ ] 弹窗/抽屉均可用 `data-close`、Esc、点遮罩三种方式关闭
- [ ] 图标全部 `data-icon`（无 emoji 图标、无裸 SVG 堆砌）；所列图标名在 ICONS 库中存在

## B. 交互完整性

- [ ] 主流程能从头点到尾（登录 → 核心 1–3 条任务 → 完成反馈）
- [ ] 每个可见按钮/单元都有行为：跳转、弹层、Toast 或 loading，无"死按钮"
- [ ] 表单：必填校验、格式校验（手机号/邮箱）、错误提示就地显示、提交有 loading + 成功 Toast
- [ ] 表格：排序可用、全选/行选联动、行菜单可开合
- [ ] 数字滚动、进度条、倒计时初始化正确（首屏与切页后均触发）

## C. 视觉还原

- [ ] 只用 `var(--…)` 令牌，无硬编码色值/字号/间距/阴影
- [ ] 4 套主题切换均不破版（逐主题截图抽查）
- [ ] 同类组件样式一致（按钮高度、圆角、标签用法统一）
- [ ] 价格/数字用 `.num` 等宽；中文文案标点规范，无半角逗号混排
- [ ] 图片位全部 `.ph` 占位且有语义 label 或图标

## D. 响应式

- [ ] 舞台条切 桌面/平板/手机 三档均可用：侧栏变抽屉、TabBar 出现、栅格降级
- [ ] 390px 宽度下无横向滚动、无文字截断（`ellipsis`/`clamp-2` 兜底）
- [ ] 弹窗在手机档不出屏（`min(宽度, calc(100vw - 24px))`）

## E. 动效

- [ ] 动效全部走 `--dur-*` / `--ease-*` 令牌
- [ ] 无循环动画堆叠（同屏 ≤1 个主动画）；列表级联 ≤8 项
- [ ] 关键操作反馈 ≤260ms 内可感知（loading/涟漪/Toast）

## F. 交付物

- [ ] 回复中包含交付说明：页面清单、主题/设备说明、交互亮点、待确认项
- [ ] `present_files` 打开 `index.html`
- [ ] 待确认事项在回复中显式列出（而非只藏在原型里）
