# 财务指标速查表

## 类型
Component Skill

## 用途
32+ SaaS 财务指标的快速参考，含公式、基准和使用场景

## 耗时
5-10 分钟

## 指标速查

### 收入指标
| 指标 | 公式 | 基准 |
|---|---|---|
| MRR | 月经常性收入 | 持续增长 |
| ARR | MRR × 12 | 持续增长 |
| ARPU | MRR / 付费用户 | 持续提升 |
| ACV | 年度合同价值 | - |
| TCV | 总合同价值 | - |

### 增长指标
| 指标 | 公式 | 基准 |
|---|---|---|
| 月增长率 | (本期MRR - 上期MRR) / 上期MRR | > 10% |
| YoY 增长率 | (本期ARR - 去年ARR) / 去年ARR | > 100% |
| 净新增ARR | 新客 + 扩展 - 收缩 - 流失 | - |

### 留存指标
| 指标 | 公式 | 基准 |
|---|---|---|
| Logo Churn | 流失客户 / 期初客户 | < 2%/月 |
| Revenue Churn | 流失收入 / 期初MRR | < 1%/月 |
| NRR | (期初 + 扩展 - 收缩 - 流失) / 期初 | > 110% |
| GRR | (期初 - 收缩 - 流失) / 期初 | > 90% |

### 效率指标
| 指标 | 公式 | 基准 |
|---|---|---|
| CAC | 获客总成本 / 新客户数 | - |
| LTV | ARPU × 毛利率 / 流失率 | LTV:CAC > 3 |
| Payback | CAC / (ARPU × 毛利率) | < 12 月 |
| 毛利率 | (收入 - COGS) / 收入 | > 70% |
| Rule of 40 | 增长率 + 利润率 | > 40% |

### 资本指标
| 指标 | 公式 | 基准 |
|---|---|---|
| Burn Rate | 月度现金消耗 | - |
| Runway | 现金 / Burn Rate | > 18 月 |
| Magic Number | 净新增ARR / 上季度S&M | > 0.75 |
