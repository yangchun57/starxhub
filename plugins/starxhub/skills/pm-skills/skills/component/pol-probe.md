# 轻量验证实验（PoL Probe）

## 类型
Component Skill

## 用途
在构建前用最小实验验证假设

## 耗时
10-30 分钟

## 框架原理

PoL（Proof of Life）Probe 是轻量级验证实验，目的是：
- 用最小成本验证关键假设
- 快速学习，避免构建无人需要的产品
- 在投入开发前降低风险
