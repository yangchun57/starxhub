# AI 推荐画布（Recommendation Canvas）

## 类型
Component Skill

## 用途
记录 AI 驱动的产品推荐设计

## 耗时
10-30 分钟

## 模板

```markdown
## AI 推荐画布

**产品/功能**：{名称}
**创建时间**：{YYYY-MM-DD}

---

### 推荐目标
- **业务目标**：{目标}
- **用户目标**：{目标}

### 推荐类型
- [ ] 个性化推荐（基于用户行为）
- [ ] 协同过滤（基于相似用户）
- [ ] 内容推荐（基于物品特征）
- [ ] 混合推荐（多种方法组合）

### 输入数据
| 数据类型 | 来源 | 质量 | 可用性 |
|---|---|---|---|
| {数据 1} | {来源} | {高/中/低} | {可用/待采集} |

### 推荐逻辑
```
IF {条件 1} AND {条件 2}
THEN 推荐 {物品}
BECAUSE {原因}
```

### 展示方式
- **位置**：{展示位置}
- **格式**：{列表/卡片/横幅}
- **数量**：{推荐数量}
- **排序**：{排序方式}

### 反馈机制
- 👍 喜欢 / 👎 不喜欢
- ⭐ 评分
- 🔄 刷新推荐
- 💬 原因说明

### 成功指标
| 指标 | 基线 | 目标 |
|---|---|---|
| 点击率 | {%} | {%} |
| 转化率 | {%} | {%} |
| 用户满意度 | {分} | {分} |

### 风险与伦理
- [ ] 隐私保护（数据脱敏）
- [ ] 公平性（无偏见）
- [ ] 透明度（可解释）
- [ ] 可控性（用户可关闭）
```
