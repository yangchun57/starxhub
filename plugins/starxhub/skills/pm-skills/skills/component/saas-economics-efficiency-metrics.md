# SaaS 单位经济学与效率指标

## 类型
Component Skill

## 用途
评估 SaaS 单位经济学和资本效率

## 耗时
10-30 分钟

## 核心指标

| 指标 | 公式 | 健康标准 |
|---|---|---|
| **CAC** | 获客总成本 / 新客户数 | 持续降低 |
| **LTV** | ARPU × 毛利率 / 月流失率 | LTV:CAC > 3 |
| **LTV:CAC** | LTV / CAC | > 3 |
| **回收期** | CAC / (ARPU × 毛利率) | < 12 个月 |
| **毛利率** | (收入 - COGS) / 收入 | > 70% |
| **Rule of 40** | 收入增长率 + 利润率 | > 40% |
| **Magic Number** | 净新增ARR / 上季度销售营销费用 | > 0.75 |
