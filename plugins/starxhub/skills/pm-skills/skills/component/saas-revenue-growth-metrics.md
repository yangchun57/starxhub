# SaaS 收入与增长指标

## 类型
Component Skill

## 用途
计算和解读 SaaS 收入、留存、增长指标

## 耗时
10-30 分钟

## 核心指标

| 指标 | 公式 | 健康标准 |
|---|---|---|
| **MRR** | 月经常性收入 | 持续增长 |
| **ARR** | MRR × 12 | 持续增长 |
| **ARPU** | MRR / 付费用户数 | 持续提升 |
| **月流失率** | 流失用户 / 总用户 | < 2% |
| **收入流失率** | 流失收入 / 期初 MRR | < 1% |
| **NRR** | (期初MRR + 扩展 - 收缩 - 流失) / 期初MRR | > 110% |
| **扩展收入占比** | 扩展收入 / 总收入 | > 20% |
