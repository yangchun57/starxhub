# 故事拆分（User Story Splitting）

## 类型
Component Skill

## 用途
8 种模式拆分大故事，使其可在一个迭代内完成

## 耗时
10-30 分钟

## 8 种拆分模式

### 1. 按工作流步骤拆分
将故事按用户工作流的步骤拆分。
```
大故事：用户可以管理订单
拆分为：
- 用户可以创建订单
- 用户可以查看订单
- 用户可以取消订单
```

### 2. 按业务规则拆分
将故事按不同的业务规则拆分。
```
大故事：用户可以支付订单
拆分为：
- 用户可以用信用卡支付
- 用户可以用支付宝支付
- 用户可以用微信支付
```

### 3. 按用户角色拆分
将故事按不同用户角色拆分。
```
大故事：用户可以管理账户
拆分为：
- 普通用户可以查看个人信息
- 管理员可以管理所有用户
```

### 4. 按数据类型拆分
将故事按不同的数据类型拆分。
```
大故事：用户可以搜索内容
拆分为：
- 用户可以搜索文章
- 用户可以搜索用户
- 用户可以搜索标签
```

### 5. 按操作类型拆分（CRUD）
将故事按创建/读取/更新/删除拆分。
```
大故事：用户可以管理任务
拆分为：
- 用户可以创建任务
- 用户可以读取任务
- 用户可以更新任务
- 用户可以删除任务
```

### 6. 按快乐路径/异常路径拆分
将故事按正常流程和异常流程拆分。
```
大故事：用户可以登录
拆分为：
- 用户可以成功登录（快乐路径）
- 用户可以处理登录失败（异常路径）
```

### 7. 按质量等级拆分
将故事按不同的质量等级拆分。
```
大故事：系统应该快速响应
拆分为：
- 页面加载 < 3 秒（MVP）
- 页面加载 < 1 秒（V2）
- 页面加载 < 500ms（V3）
```

### 8. 按 MVP 范围拆分
将故事按 MVP 必需和可选拆分。
```
大故事：用户可以分享内容
拆分为：
- 用户可以复制链接分享（MVP）
- 用户可以分享到社交媒体（V2）
- 用户可以邀请好友协作（V3）
```
