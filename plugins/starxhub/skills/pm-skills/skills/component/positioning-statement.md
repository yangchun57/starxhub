# 产品定位声明（Positioning Statement）

## 类型
Component Skill

## 用途
使用 Geoffrey Moore 模板定义产品定位，明确服务对象、解决的问题和差异化优势

## 耗时
10-30 分钟

## 框架原理

产品定位是营销和产品的基石，好的定位应该：
- **目标明确**：清楚定义目标客户
- **问题清晰**：明确要解决的问题
- **差异化**：与竞品的本质区别
- **可验证**：能用事实证明

## Geoffrey Moore 模板

```
对于 [目标客户]
他们 [需要解决的问题]
我们的 [产品名称] 是 [产品类别]
它能够 [关键价值]
不同于 [竞品]
我们的优势是 [差异化优势]
```

## 执行步骤

### 第一步：明确目标客户（10 分钟）

**核心问题**：
1. 谁是最有价值的客户？
2. 他们有什么共同特征？
3. 他们的使用场景是什么？

**输出**：
```markdown
**目标客户**：
{具体描述目标客户，避免"所有人"}

**客户特征**：
- {特征 1}
- {特征 2}

**使用场景**：
- {场景 1}
- {场景 2}
```

### 第二步：定义问题（10 分钟）

**核心问题**：
1. 目标客户面临什么问题？
2. 这个问题有多严重？
3. 现有解决方案的不足？

**输出**：
```markdown
**核心问题**：
{描述问题，用数据支撑}

**问题严重性**：
{量化影响，如时间损失、收入损失}

**现有方案不足**：
- {不足 1}
- {不足 2}
```

### 第三步：定义产品类别（5 分钟）

**核心问题**：
1. 产品属于什么类别？
2. 客户如何理解这个类别？
3. 是否有新的类别机会？

**输出**：
```markdown
**产品类别**：
{类别名称}

**类别定义**：
{客户如何理解这个类别}

**类别优势**：
{为什么这个类别有利于定位}
```

### 第四步：阐述关键价值（10 分钟）

**核心问题**：
1. 产品如何解决这个问题？
2. 客户能获得什么价值？
3. 价值可量化吗？

**输出**：
```markdown
**关键价值**：
{一句话描述核心价值}

**价值量化**：
- {价值 1}（量化）
- {价值 2}（量化）

**价值证明**：
- {证据 1}
- {证据 2}
```

### 第五步：识别竞品（5 分钟）

**核心问题**：
1. 客户目前用什么解决方案？
2. 直接竞品是谁？
3. 间接竞品是谁？

**输出**：
```markdown
**直接竞品**：
- {竞品 1}
- {竞品 2}

**间接竞品**：
- {竞品 3}（替代方案）
- {竞品 4}（现状）

**竞品不足**：
- {不足 1}
- {不足 2}
```

### 第六步：明确差异化优势（10 分钟）

**核心问题**：
1. 与竞品的本质区别是什么？
2. 这个区别对客户重要吗？
3. 能持续保持吗？

**输出**：
```markdown
**差异化优势**：
{一句话描述差异化}

**优势证明**：
- {证据 1}
- {证据 2}

**可持续性**：
{为什么能持续保持优势}
```

## 定位声明模板

```markdown
## 产品定位声明

**产品名称**：{名称}
**定位时间**：{YYYY-MM-DD}

---

### 定位声明

对于 {目标客户}
他们 {需要解决的问题}
我们的 {产品名称} 是 {产品类别}
它能够 {关键价值}
不同于 {竞品}
我们的优势是 {差异化优势}

---

### 详细解析

**目标客户**：
{详细描述}

**核心问题**：
{问题描述 + 数据支撑}

**产品类别**：
{类别定义}

**关键价值**：
{价值描述 + 量化}

**竞品对比**：
| 维度 | 我们 | 竞品 A | 竞品 B |
|---|---|---|---|
| {维度 1} | {优势} | {劣势} | {劣势} |

**差异化优势**：
{优势描述 + 证明}

---

### 定位验证

**客户验证**：
- [ ] 目标客户能理解定位
- [ ] 客户认可问题的重要性
- [ ] 客户认可差异化优势

**内部验证**：
- [ ] 团队能清晰复述定位
- [ ] 定位与产品能力匹配
- [ ] 定位与业务目标一致

---

### 定位应用

**营销文案**：
{基于定位的营销文案}

**销售话术**：
{基于定位的销售话术}

**产品决策**：
{基于定位的产品决策原则}
```

## 示例

### 示例 1：Slack 的早期定位

```
对于 知识工作者团队
他们 需要高效的团队沟通工具
我们的 Slack 是 团队沟通平台
它能够 将团队沟通集中化，减少邮件往来
不同于 Email 和 HipChat
我们的优势是 频道组织 + 第三方集成 + 搜索能力
```

### 示例 2：多租户 SaaS 插件

```
对于 中大型企业的产品团队
他们 需要快速搭建多租户 SaaS 产品
我们的 starxhub 是 Claude Code 多 Agent 开发框架
它能够 在 1 天内生成完整的多租户 SaaS 脚手架
不同于 手动搭建或使用通用脚手架
我们的优势是 内置 24 个 PM Agent + 多租户护栏 + 完整开发规范
```

## 反模式警示

### ❌ 反模式 1：目标客户太宽泛
**问题**："所有人"或"企业客户"
**解决**：具体到行业、规模、角色

### ❌ 反模式 2：差异化不明显
**问题**："更好"、"更快"、"更便宜"
**解决**：找出本质区别，如"唯一支持 X 的产品"

### ❌ 反模式 3：定位与产品不符
**问题**：定位很美好，产品做不到
**解决**：定位要基于真实能力，可验证

## 质量检查清单

- [ ] 目标客户具体，不是"所有人"
- [ ] 问题描述清晰，有数据支撑
- [ ] 产品类别明确，客户能理解
- [ ] 关键价值可量化
- [ ] 竞品识别完整（直接 + 间接）
- [ ] 差异化优势明显且可持续
- [ ] 定位声明简洁，能一句话复述
