# PESTEL 分析

## 类型
Component Skill

## 用途
分析外部宏观因素（政治/经济/社会/技术/环境/法律）

## 耗时
30-60 分钟

## 框架原理

PESTEL 帮助识别影响产品的外部因素：
- **P**olitical（政治）：政策、监管、贸易
- **E**conomic（经济）：增长、通胀、汇率
- **S**ocial（社会）：人口、文化、消费习惯
- **T**echnological（技术）：创新、自动化、技术趋势
- **E**nvironmental（环境）：气候、资源、可持续性
- **L**egal（法律）：法规、合规、知识产权
