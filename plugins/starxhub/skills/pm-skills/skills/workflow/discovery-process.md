# 发现流程（Discovery Process）

## 类型
Workflow Skill

## 用途
完整的发现周期：问题框架 → 研究 → 综合 → 验证

## 耗时
3-4 周

## 框架原理

发现流程的 4 个阶段：
1. **问题框架**（3-5 天）：明确要解决的问题
2. **研究**（1-2 周）：收集用户和市场数据
3. **综合**（3-5 天）：分析数据，提炼洞察
4. **验证**（3-5 天）：验证假设和方案

## 执行流程

### 阶段 1：问题框架（3-5 天）

**目标**：明确要解决的问题，定义成功标准

**活动**：
1. 利益相关者访谈
2. 问题陈述撰写
3. 成功指标定义
4. 范围界定

**输出**：
```markdown
## 问题框架文档

### 问题陈述
{描述}

### 成功指标
| 指标 | 基线 | 目标 |
|---|---|---|
| {指标} | {值} | {值} |

### 范围
- 包含：{内容}
- 排除：{内容}

### 假设
- {假设 1}
- {假设 2}
```

### 阶段 2：研究（1-2 周）

**目标**：收集用户和市场数据

**活动**：
1. 用户访谈（5-10 人）
2. 竞品分析
3. 数据分析
4. 市场趋势研究

**输出**：
```markdown
## 研究数据

### 用户访谈洞察
| 洞察 | 来源 | 重要性 |
|---|---|---|
| {洞察} | {来源} | {高/中/低} |

### 竞品分析
| 竞品 | 优势 | 劣势 |
|---|---|---|
| {竞品} | {优势} | {劣势} |

### 数据发现
- {发现 1}
- {发现 2}
```

### 阶段 3：综合（3-5 天）

**目标**：分析数据，提炼洞察

**活动**：
1. 亲和图分析
2. 用户画像创建
3. 机会识别
4. 机会方案树生成

**输出**：
```markdown
## 综合报告

### 用户画像
| 画像 | 特征 | 需求 |
|---|---|---|
| {画像} | {特征} | {需求} |

### 机会清单
| 机会 | 影响 | 可行性 |
|---|---|---|
| {机会} | {高/中/低} | {高/中/低} |

### 机会方案树
{树状图}
```

### 阶段 4：验证（3-5 天）

**目标**：验证假设和方案

**活动**：
1. 原型设计
2. 用户测试
3. 假设验证
4. 决策文档

**输出**：
```markdown
## 验证报告

### 测试结果
| 假设 | 验证方法 | 结果 | 结论 |
|---|---|---|---|
| {假设} | {方法} | {结果} | {验证/未验证} |

### 决策
- **继续**：{原因}
- **调整**：{原因}
- **放弃**：{原因}

### 下一步
- [ ] {行动 1}
- [ ] {行动 2}
```

## 质量检查清单

- [ ] 问题陈述清晰，有证据支撑
- [ ] 用户访谈覆盖目标用户
- [ ] 竞品分析完整
- [ ] 用户画像基于真实数据
- [ ] 机会方案树完整
- [ ] 假设经过验证
- [ ] 决策有数据支撑
