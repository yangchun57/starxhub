# 高管入职手册（Executive Onboarding Playbook）

## 类型
Workflow Skill

## 用途
VP/CPO 30-60-90 天诊断手册

## 耗时
30-60-90 天

## 框架原理

高管入职的 3 个阶段：
1. **30 天：学习与诊断** - 了解现状，建立关系
2. **60 天：规划与对齐** - 制定计划，获得支持
3. **90 天：执行与交付** - 开始执行，早期胜利

## 执行流程

### 30 天：学习与诊断

**目标**：了解现状，建立关系，识别关键问题

**第 1 周：入职准备**
- [ ] 了解公司使命、愿景、价值观
- [ ] 熟悉组织架构和关键人员
- [ ] 审阅现有产品文档和战略
- [ ] 设置 1:1 会议（直接下属、关键利益相关者）

**第 2 周：团队诊断**
- [ ] 与每个直接下属 1:1
- [ ] 评估团队能力、士气、文化
- [ ] 了解当前项目和优先级
- [ ] 识别团队优势和差距

**第 3 周：业务诊断**
- [ ] 审阅产品指标和 KPI
- [ ] 了解客户反馈和 NPS
- [ ] 分析竞争格局
- [ ] 了解技术债务和架构

**第 4 周：利益相关者诊断**
- [ ] 与高管团队 1:1
- [ ] 与销售、市场、客户成功团队对齐
- [ ] 了解董事会期望
- [ ] 识别关键利益相关者

**30 天输出**：
```markdown
## 30 天诊断报告

### 团队现状
- **优势**：{优势}
- **差距**：{差距}
- **士气**：{评估}

### 业务现状
- **产品指标**：{指标}
- **客户反馈**：{反馈}
- **竞争格局**：{格局}

### 关键问题
1. {问题 1}
2. {问题 2}

### 早期机会
1. {机会 1}
2. {机会 2}
```

### 60 天：规划与对齐

**目标**：制定计划，获得支持，建立信任

**第 5-6 周：战略制定**
- [ ] 制定产品愿景和战略
- [ ] 定义关键优先级
- [ ] 制定 90 天计划
- [ ] 制定 6-12 个月路线图

**第 7 周：计划对齐**
- [ ] 与直接下属对齐计划
- [ ] 与高管团队对齐计划
- [ ] 与董事会对齐计划
- [ ] 收集反馈并调整

**第 8 周：资源规划**
- [ ] 评估资源需求
- [ ] 识别招聘需求
- [ ] 制定预算计划
- [ ] 建立度量体系

**60 天输出**：
```markdown
## 60 天计划

### 产品愿景
{愿景}

### 关键优先级
1. {优先级 1}
2. {优先级 2}
3. {优先级 3}

### 90 天计划
| 优先级 | 目标 | 关键结果 | 负责人 |
|---|---|---|---|
| {优先级} | {目标} | {KR} | {负责人} |

### 资源需求
- {需求 1}
- {需求 2}

### 度量体系
| 指标 | 基线 | 目标 |
|---|---|---|
| {指标} | {值} | {值} |
```

### 90 天：执行与交付

**目标**：开始执行，交付早期胜利，建立信任

**第 9-10 周：启动执行**
- [ ] 启动关键项目
- [ ] 建立周会机制
- [ ] 开始 1:1 辅导
- [ ] 追踪关键指标

**第 11-12 周：早期胜利**
- [ ] 交付第一个里程碑
- [ ] 分享早期成果
- [ ] 收集反馈
- [ ] 调整计划

**第 13 周：评估与调整**
- [ ] 评估 90 天成果
- [ ] 识别成功和失败
- [ ] 调整后续计划
- [ ] 制定下一个 90 天计划

**90 天输出**：
```markdown
## 90 天评估

### 交付成果
1. {成果 1}
2. {成果 2}

### 关键指标
| 指标 | 基线 | 当前 | 目标 |
|---|---|---|---|
| {指标} | {值} | {值} | {值} |

### 成功与失败
**成功**：
- {成功 1}

**失败**：
- {失败 1}

**学习**：
- {学习 1}

### 下一个 90 天
- {计划 1}
- {计划 2}
```

## 质量检查清单

- [ ] 30 天完成全面诊断
- [ ] 60 天完成战略制定
- [ ] 90 天交付早期胜利
- [ ] 建立关键关系
- [ ] 获得高管支持
- [ ] 建立度量体系
