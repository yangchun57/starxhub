# 技能编写工作流（Skill Authoring Workflow）

## 类型
Workflow Skill

## 用途
元技能：指导如何创建和编辑新的 PM 技能

## 耗时
1-3 天

## 框架原理

技能编写的 5 个阶段：
1. **定义**：明确技能的目的和边界
2. **设计**：设计技能的交互流程
3. **开发**：编写技能文档
4. **测试**：测试技能效果
5. **迭代**：根据反馈改进

## 执行流程

### 阶段 1：定义（2-4 小时）

**目标**：明确技能的目的、边界和成功标准

**活动**：
1. 确定技能类型（Component/Interactive/Workflow）
2. 定义技能目的
3. 明确边界（做什么/不做什么）
4. 定义成功标准

**输出**：
```markdown
## 技能定义

### 基本信息
- **名称**：{名称}
- **类型**：{Component/Interactive/Workflow}
- **耗时**：{时间}

### 目的
{一句话描述技能目的}

### 边界
**做什么**：
- {功能 1}
- {功能 2}

**不做什么**：
- {排除 1}
- {排除 2}

### 成功标准
- [ ] {标准 1}
- [ ] {标准 2}
```

### 阶段 2：设计（4-8 小时）

**目标**：设计技能的交互流程和输出模板

**活动**：
1. 设计交互流程（Interactive/Workflow）
2. 设计输出模板
3. 设计质量检查清单
4. 识别与其他技能的协作

**输出**：
```markdown
## 技能设计

### 交互流程
1. {步骤 1}
2. {步骤 2}
3. {步骤 3}

### 输出模板
{模板}

### 质量检查清单
- [ ] {检查项 1}
- [ ] {检查项 2}

### 协作技能
- **上游**：{技能}
- **下游**：{技能}
```

### 阶段 3：开发（1-2 天）

**目标**：编写技能文档

**活动**：
1. 编写框架原理
2. 编写执行步骤
3. 编写示例
4. 编写反模式警示
5. 编写输出模板

**输出**：
```markdown
# {技能名称}

## 类型
{Component/Interactive/Workflow} Skill

## 用途
{一句话描述}

## 耗时
{时间}

## 框架原理
{原理}

## 执行流程
{流程}

## 示例
{示例}

## 反模式警示
{反模式}

## 输出模板
{模板}
```

### 阶段 4：测试（4-8 小时）

**目标**：测试技能效果

**活动**：
1. 自己测试技能
2. 邀请他人测试
3. 收集反馈
4. 识别问题

**输出**：
```markdown
## 测试报告

### 测试场景
- {场景 1}
- {场景 2}

### 测试结果
| 场景 | 结果 | 问题 |
|---|---|---|
| {场景} | {结果} | {问题} |

### 反馈
- {反馈 1}
- {反馈 2}

### 改进建议
- {建议 1}
- {建议 2}
```

### 阶段 5：迭代（4-8 小时）

**目标**：根据反馈改进技能

**活动**：
1. 修复问题
2. 优化流程
3. 完善模板
4. 更新文档

**输出**：
```markdown
## 迭代记录

### 版本 1.1
- **修复**：{问题}
- **优化**：{优化}
- **更新**：{更新}

### 版本 1.2
- **修复**：{问题}
- **优化**：{优化}
- **更新**：{更新}
```

## 技能文档结构

```markdown
# {技能名称}

## 类型
{Component/Interactive/Workflow} Skill

## 用途
{一句话描述}

## 耗时
{时间}

## 框架原理
{原理解释}

## 执行流程
### 第一步：{步骤名}（{时间}）
{步骤说明}

### 第二步：{步骤名}（{时间}）
{步骤说明}

## 示例
{完整示例}

## 反模式警示
### ❌ 反模式 1：{名称}
**问题**：{描述}
**解决**：{方法}

## 输出模板
{模板}

## 质量检查清单
- [ ] {检查项 1}
- [ ] {检查项 2}

## 与其他技能的协作
- **上游**：{技能}
- **下游**：{技能}
```

## 质量检查清单

- [ ] 技能目的明确
- [ ] 边界清晰
- [ ] 流程完整
- [ ] 示例具体
- [ ] 反模式警示
- [ ] 输出模板完整
- [ ] 质量检查清单
- [ ] 经过测试

## 与其他技能的协作

- **并行**：所有技能都可以作为参考
- **下游**：新创建的技能
