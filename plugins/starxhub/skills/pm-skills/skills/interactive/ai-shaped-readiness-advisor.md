# AI 产品就绪顾问（AI-Shaped Readiness Advisor）

## 类型
Interactive Skill

## 用途
评估你是自动化任务（AI-first）还是重新设计工作方式（AI-shaped）

## 耗时
30-60 分钟

## 框架原理

两种 AI 产品思路：

| 思路 | 定义 | 特点 |
|---|---|---|
| **AI-first** | 自动化现有任务 | 用 AI 替代人工，效率提升 |
| **AI-shaped** | 重新设计工作方式 | 用 AI 改变工作本质，价值创造 |

## 交互流程

### 第一步：评估当前状态（20 分钟）

**核心问题**：
1. 你在用 AI 做什么？
2. 是自动化还是重新设计？
3. 效果如何？

**输出**：
```markdown
## AI 产品就绪评估

### 当前 AI 应用
| 应用 | 类型 | 效果 |
|---|---|---|
| {应用 1} | {AI-first/AI-shaped} | {效果} |

### 5 项能力评估
| 能力 | 评分 | 说明 |
|---|---|---|
| 数据就绪度 | {分}/10 | {说明} |
| 团队能力 | {分}/10 | {说明} |
| 技术基础设施 | {分}/10 | {说明} |
| 组织文化 | {分}/10 | {说明} |
| 商业模型 | {分}/10 | {说明} |

### 总体评分：{分}/50
```

### 第二步：推荐发展方向（20 分钟）

**推荐逻辑**：
```
IF 评分 < 25:
    推荐：先建立基础能力，再考虑 AI-shaped
    
IF 评分 25-40:
    推荐：从 AI-first 开始，逐步过渡到 AI-shaped
    
IF 评分 > 40:
    推荐：直接追求 AI-shaped，重新设计工作方式
```

### 第三步：制定行动计划（20 分钟）

**输出**：
```markdown
## 行动计划

### 短期（3 个月）
- [ ] {行动 1}
- [ ] {行动 2}

### 中期（6 个月）
- [ ] {行动 1}
- [ ] {行动 2}

### 长期（12 个月）
- [ ] {行动 1}
- [ ] {行动 2}
```

## 反模式

- ❌ 只做 AI-first：忽视 AI-shaped 的价值
- ❌ 跳过基础：没有数据和文化基础，直接 AI-shaped
- ❌ 忽视组织：只关注技术，忽视人和流程
