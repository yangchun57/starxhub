# 业务健康诊断（Business Health Diagnostic）

## 类型
Interactive Skill

## 用途
诊断 SaaS 业务健康度，识别增长、留存、效率、资本方面的问题

## 耗时
30-90 分钟

## 框架原理

SaaS 业务健康度从 4 个维度评估：
- **增长健康**：收入增长、客户获取、市场扩张
- **留存健康**：客户留存、流失率、扩展收入
- **效率健康**：单位经济学、运营成本、人效
- **资本健康**：现金流、融资能力、估值

## 诊断流程

### 第一步：数据收集（15 分钟）

**核心指标**：
```
收入指标：
- MRR/ARR（月/年经常性收入）
- 收入增长率（月环比、年同比）
- ARPU（每用户平均收入）

留存指标：
- 月流失率（Logo Churn）
- 收入流失率（Revenue Churn）
- NRR（净收入留存率）
- 扩展收入占比

效率指标：
- CAC（客户获取成本）
- LTV（客户生命周期价值）
- LTV:CAC 比率
- 回收期（Payback Period）
- 毛利率

资本指标：
- 现金流（月度）
- 融资轮次和估值
- Rule of 40（增长率 + 利润率）
```

### 第二步：健康度评估（30 分钟）

**评估标准**：

| 维度 | 健康 | 警告 | 危险 |
|---|---|---|---|
| **增长** | 月增长 > 10% | 月增长 5-10% | 月增长 < 5% |
| **留存** | 月流失 < 2% | 月流失 2-5% | 月流失 > 5% |
| **效率** | LTV:CAC > 3 | LTV:CAC 2-3 | LTV:CAC < 2 |
| **资本** | 现金流正 | 现金流负但可控 | 现金流负且恶化 |

### 第三步：问题诊断（30 分钟）

**诊断逻辑**：

```
IF 月流失率 > 5%:
    诊断：留存问题
    根因：产品价值不足 / 客户成功缺失 / 定价不合理
    建议：加强客户成功团队 / 优化 onboarding / 调整定价
    
IF LTV:CAC < 2:
    诊断：效率问题
    根因：获客成本过高 / 客户生命周期过短
    建议：优化获客渠道 / 提升留存 / 提高 ARPU
    
IF 收入增长 < 5% AND 流失率 < 2%:
    诊断：增长问题
    根因：获客不足 / 市场饱和 / 产品扩展性差
    建议：增加获客投入 / 扩展市场 / 增加功能
    
IF 现金流负 AND 融资困难:
    诊断：资本问题
    根因：烧钱过快 / 收入不足 / 估值过低
    建议：控制成本 / 提升收入 / 调整融资策略
```

### 第四步：输出报告（15 分钟）

**报告结构**：
```markdown
## 业务健康诊断报告

### 总体评分
- 增长健康：{评分} / 100
- 留存健康：{评分} / 100
- 效率健康：{评分} / 100
- 资本健康：{评分} / 100
- 综合评分：{评分} / 100

### 关键发现
1. {发现 1}
2. {发现 2}

### 问题诊断
| 问题 | 严重级别 | 根因 | 建议 |
|---|---|---|---|
| {问题 1} | {高/中/低} | {根因} | {建议} |

### 优先行动
1. {行动 1}（立即）
2. {行动 2}（本周）

```

## 示例诊断

### 示例 1：留存问题

**输入数据**：
```
MRR: $50,000
月流失率: 8%
NRR: 95%
LTV:CAC: 2.5
```

**诊断结果**：
```
❌ 留存健康：危险（月流失 8% > 5%）
⚠️ 效率健康：警告（LTV:CAC 2.5 < 3）

根因分析：
- 月流失 8% 复利约 63% 年化流失
- NRR 95% 说明扩展收入不足以弥补流失
- LTV:CAC 2.5 说明获客效率一般

优先行动：
1. 立即：分析流失客户队列，识别流失原因
2. 本周：加强客户成功团队，优化 onboarding
3. 本月：推出客户健康评分系统，提前干预
```

### 示例 2：增长问题

**输入数据**：
```
MRR: $100,000
月增长率: 3%
月流失率: 1%
LTV:CAC: 4
```

**诊断结果**：
```
✅ 留存健康：健康（月流失 1% < 2%）
✅ 效率健康：健康（LTV:CAC 4 > 3）
⚠️ 增长健康：警告（月增长 3% < 5%）

根因分析：
- 留存和效率都很好，但增长缓慢
- 可能原因：获客投入不足 / 市场饱和 / 产品扩展性差

优先行动：
1. 立即：评估获客渠道，增加高 ROI 渠道投入
2. 本周：调研新市场（地域/行业/客群）
3. 本月：推出扩展功能，提升 ARPU
```

## 反模式警示

### ❌ 反模式 1：只看收入增长
**问题**：忽视留存和效率，盲目获客
**解决**：4 个维度综合评估

### ❌ 反模式 2：忽视流失率
**问题**：只关注新客户，忽视老客户流失
**解决**：流失率 > 5% 是危险信号，立即干预

### ❌ 反模式 3：过度优化 LTV:CAC
**问题**：为了提升比率而减少获客投入
**解决**：LTV:CAC > 3 是健康，但不必追求过高
