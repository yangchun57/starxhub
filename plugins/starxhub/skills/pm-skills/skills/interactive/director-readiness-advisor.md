# Director 转型顾问（Director Readiness Advisor）

## 类型
Interactive Skill

## 用途
教练式指导 PM 向 Director 转型，覆盖 4 种情境

## 耗时
30-90 分钟

## 框架原理

PM→Director 转型的 4 种情境：
1. **准备中**：还在 PM 岗位，准备晋升
2. **面试中**：正在面试 Director 职位
3. **新上任**：刚成为 Director，需要站稳
4. **重新校准**：已是 Director，需要调整

## 交互流程

### 第一步：识别情境（10 分钟）

**核心问题**：
1. 你目前处于哪个阶段？
2. 最大的挑战是什么？
3. 期望获得什么帮助？

### 第二步：诊断差距（20 分钟）

**输出**：
```markdown
## 转型诊断

**当前情境**：{准备中/面试中/新上任/重新校准}

### 优势
- {优势 1}
- {优势 2}

### 差距
- {差距 1}
- {差距 2}

### 关键挑战
- {挑战 1}
- {挑战 2}
```

### 第三步：制定计划（30 分钟）

**输出**：
```markdown
## 转型计划

### 短期（30 天）
- [ ] {行动 1}
- [ ] {行动 2}

### 中期（60 天）
- [ ] {行动 1}
- [ ] {行动 2}

### 长期（90 天）
- [ ] {行动 1}
- [ ] {行动 2}

### 资源需求
- {资源 1}
- {资源 2}

### 成功指标
- {指标 1}
- {指标 2}
```

## 反模式

- ❌ 只做战术执行：要提升到战略层面
- ❌ 忽视跨团队影响：要关注组织层面
- ❌ 不寻求反馈：要主动寻求上级和同侪反馈
