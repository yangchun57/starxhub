# 定位工作坊（Positioning Workshop）

## 类型
Interactive Skill

## 用途
引导式定位定义，使用自适应发现问题

## 耗时
60-120 分钟

## 框架原理

定位工作坊的核心：
- **目标客户**：为谁服务？
- **未满足需求**：解决什么问题？
- **产品类别**：属于什么类别？
- **差异化优势**：为什么选你？

## 交互流程

### 第一步：定义目标客户（20 分钟）

**核心问题**：
1. 谁是最有价值的客户？
2. 他们有什么共同特征？
3. 他们的使用场景是什么？

**输出**：
```markdown
## 目标客户

**画像**：{描述}
**特征**：
- {特征 1}
- {特征 2}

**场景**：
- {场景 1}
- {场景 2}
```

### 第二步：识别未满足需求（20 分钟）

**核心问题**：
1. 他们面临什么问题？
2. 现有方案的不足？
3. 他们的期望是什么？

**输出**：
```markdown
## 未满足需求

**核心问题**：{描述}
**现有方案不足**：
- {不足 1}
- {不足 2}

**期望**：
- {期望 1}
- {期望 2}
```

### 第三步：定义差异化（20 分钟）

**核心问题**：
1. 与竞品的本质区别？
2. 这个区别重要吗？
3. 能持续保持吗？

**输出**：
```markdown
## 定位声明

对于 {目标客户}
他们 {未满足需求}
我们的 {产品名} 是 {产品类别}
它能够 {差异化优势}
不同于 {竞品}
```

### 第四步：验证定位（20 分钟）

**验证问题**：
- [ ] 目标客户能理解
- [ ] 客户认可需求
- [ ] 差异化明显
- [ ] 团队能复述

**输出**：
```markdown
## 验证结果

### 通过
- {通过项}

### 需要改进
- {改进项}

### 下一步
- [ ] {行动 1}
- [ ] {行动 2}
```

## 反模式

- ❌ 目标太宽泛："所有人"
- ❌ 差异化不明显："更好"
- ❌ 不验证：定位需要客户验证
