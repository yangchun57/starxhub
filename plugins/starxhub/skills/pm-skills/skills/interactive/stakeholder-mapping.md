# 利益相关者映射（Stakeholder Mapping）

## 类型
Interactive Skill

## 用途
运行两个互补网格（权力×兴趣 + 影响×权力），找出盲区

## 耗时
30-60 分钟

## 框架原理

两个网格帮助从不同角度理解利益相关者：

**网格 1：权力×兴趣（Power × Interest）**
- 用于制定参与策略
- 高权力高兴趣：密切管理
- 高权力低兴趣：保持满意
- 低权力高兴趣：保持知情
- 低权力低兴趣：监控

**网格 2：影响×权力（Impact × Power）**
- 用于决定谁的聲音需要被提升
- 高影响高权力：关键决策者
- 高影响低权力：需要赋权
- 低影响高权力：需要说服
- 低影响低权力：可以忽视

## 交互流程

### 第一步：权力×兴趣网格（20 分钟）

**输出**：
```markdown
## 权力×兴趣网格

### 高权力高兴趣（密切管理）
- {姓名}：{原因}

### 高权力低兴趣（保持满意）
- {姓名}：{原因}

### 低权力高兴趣（保持知情）
- {姓名}：{原因}

### 低权力低兴趣（监控）
- {姓名}：{原因}
```

### 第二步：影响×权力网格（20 分钟）

**输出**：
```markdown
## 影响×权力网格

### 高影响高权力（关键决策者）
- {姓名}：{原因}

### 高影响低权力（需要赋权）
- {姓名}：{原因}

### 低影响高权力（需要说服）
- {姓名}：{原因}

### 低影响低权力（可以忽视）
- {姓名}：{原因}
```

### 第三步：对比分析（10 分钟）

**输出**：
```markdown
## 对比分析

### 盲区
{两个网格之间的差异，找出被忽视的利益相关者}

### 行动建议
- {建议 1}
- {建议 2}
```

## 反模式

- ❌ 只用一个网格：两个网格互补，缺一不可
- ❌ 不更新：利益相关者会变化
- ❌ 忽视低权力高影响：这些人可能被忽视但很重要
