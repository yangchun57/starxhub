# 利益相关者参与顾问（Stakeholder Engagement Advisor）

## 类型
Interactive Skill

## 用途
为每个利益相关者制定个性化的参与策略

## 耗时
30-60 分钟

## 框架原理

每个利益相关者都需要：
- **定制的信息框架**：他们关心什么？
- **合适的媒介**：什么方式最有效？
- **适当的频率**：多久沟通一次？
- **明确的下一步**：具体行动是什么？

## 交互流程

### 第一步：分析利益相关者（15 分钟）

**核心问题**：
1. 他们最关心什么？
2. 他们的决策风格是什么？
3. 他们偏好的沟通方式？
4. 他们目前的态度？

### 第二步：制定策略（20 分钟）

**输出**：
```markdown
## 利益相关者参与策略

**利益相关者**：{姓名}
**角色**：{角色}
**当前态度**：{支持/中立/反对}

### 信息框架
**核心信息**：{一句话}
**支撑点**：
- {支撑点 1}
- {支撑点 2}

### 沟通计划
| 媒介 | 频率 | 内容 |
|---|---|---|
| {媒介} | {频率} | {内容} |

### 下一步行动
- [ ] {行动 1}
- [ ] {行动 2}

### 风险与缓解
- **风险**：{风险}
- **缓解**：{缓解措施}
```

## 反模式

- ❌ 一刀切：每个利益相关者都需要定制策略
- ❌ 忽视态度：反对者需要不同的策略
- ❌ 没有下一步：沟通后要有明确的行动
