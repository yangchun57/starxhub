# 访谈准备（Discovery Interview Prep）

## 类型
Interactive Skill

## 用途
基于 Mom Test 风格规划用户访谈，获取真实有效的用户洞察

## 耗时
30-60 分钟

## 框架原理

Mom Test 的核心原则：
- **不问观点**：问过去的行为，不问未来的意图
- **不问假设**：让用户自己说出问题
- **倾听为主**：80% 听，20% 问
- **验证问题**：确认问题真实存在

## 执行流程

### 第一步：明确研究目标（10 分钟）

**核心问题**：
1. 我们想验证什么假设？
2. 需要了解什么信息？
3. 如何判断访谈成功？

**输出**：
```markdown
## 研究目标

**核心假设**：{假设}
**需要了解**：
- {问题 1}
- {问题 2}

**成功标准**：
- {标准 1}
- {标准 2}
```

### 第二步：识别目标用户（10 分钟）

**用户筛选标准**：
- 是目标客户吗？
- 经历过这个问题吗？
- 愿意分享吗？

**输出**：
```markdown
## 目标用户

**用户画像**：{画像}
**筛选标准**：
- {标准 1}
- {标准 2}

**招募渠道**：
- {渠道 1}
- {渠道 2}
```

### 第三步：设计访谈问题（20 分钟）

**Mom Test 问题设计**：

❌ **错误问题**：
```
"你觉得这个功能有用吗？"（问观点）
"你会用这个产品吗？"（问未来意图）
"这个解决方案好吗？"（问假设）
```

✅ **正确问题**：
```
"上次遇到这个问题是什么时候？"（问过去行为）
"你是怎么解决的？"（问当前方案）
"这个问题给你造成了什么影响？"（问真实痛点）
```

**问题结构**：
```markdown
## 访谈问题

### 开场（5 分钟）
1. 请介绍一下你的工作/角色？
2. 你日常工作中最耗时的任务是什么？

### 探索问题（20 分钟）
3. 上次遇到 [问题] 是什么时候？
4. 当时你是怎么解决的？
5. 这个解决方案有什么不足？
6. 这个问题给你造成了什么影响？（时间/金钱/精力）

### 深入挖掘（10 分钟）
7. 如果有一个完美的解决方案，它应该具备什么？
8. 你愿意为解决这个问题付多少钱？
9. 还有其他相关问题吗？

### 结束（5 分钟）
10. 还有什么想补充的吗？
11. 可以推荐其他受访者吗？
```

### 第四步：准备访谈材料（10 分钟）

**材料清单**：
- [ ] 访谈问题清单
- [ ] 录音设备（需征得同意）
- [ ] 笔记模板
- [ ] 受访者信息表
- [ ] 感谢礼品（如有）

### 第五步：访谈执行指南（5 分钟）

**访谈技巧**：
- **多问"为什么"**：挖掘深层原因
- **追问具体事例**：避免泛泛而谈
- **注意非语言信号**：表情、语气、停顿
- **不要推销**：倾听为主，不要说服

**常见陷阱**：
- ❌ 问引导性问题："你不觉得这个功能有用吗？"
- ❌ 过早介绍方案：先听问题，再谈方案
- ❌ 忽视负面信号：用户犹豫、敷衍

## 访谈问题模板

```markdown
# 用户访谈问题清单

**研究目标**：{目标}
**目标用户**：{用户}
**访谈时长**：30-45 分钟

---

## 开场（5 分钟）

1. 请介绍一下你的工作/角色？
2. 你日常工作中最耗时的任务是什么？

---

## 探索问题（20 分钟）

3. 上次遇到 [问题] 是什么时候？
   - 追问：当时具体情况是什么？
   
4. 你是怎么解决的？
   - 追问：用了什么工具/方法？
   
5. 这个解决方案有什么不足？
   - 追问：最让你头疼的是什么？
   
6. 这个问题给你造成了什么影响？
   - 追问：浪费了多长时间/金钱？

---

## 深入挖掘（10 分钟）

7. 如果有一个完美的解决方案，它应该具备什么？
   - 追问：最重要的 3 个功能是什么？
   
8. 你愿意为解决这个问题付多少钱？
   - 追问：为什么是这个价格？
   
9. 还有其他相关问题吗？

---

## 结束（5 分钟）

10. 还有什么想补充的吗？
11. 可以推荐其他受访者吗？

---
```

## 反模式警示

### ❌ 反模式 1：问观点而非行为
**问题**："你觉得这个功能有用吗？"
**解决**："上次遇到这个问题是怎么解决的？"

### ❌ 反模式 2：过早介绍方案
**问题**：还没了解问题就推销产品
**解决**：先听问题，再谈方案

### ❌ 反模式 3：忽视负面信号
**问题**：用户犹豫、敷衍时继续追问
**解决**：识别信号，适时结束或转换话题
