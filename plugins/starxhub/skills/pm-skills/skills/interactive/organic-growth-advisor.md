# 有机增长顾问（Organic Growth Advisor）

## 类型
Interactive Skill

## 用途
McKinsey 增长金字塔：诊断增长约束在新细分市场、地域、渠道还是产品

## 耗时
30-90 分钟

## 框架原理

McKinsey 增长金字塔帮助识别增长约束：

```
                    新产品
                   /      \
              新市场        新渠道
             /    \        /    \
        新地域   新客群  线上   线下
```

## 交互流程

### 第一步：诊断增长约束（20 分钟）

**核心问题**：
1. 当前增长瓶颈在哪里？
2. 哪个维度最有潜力？
3. 资源约束是什么？

**输出**：
```markdown
## 增长诊断

### 当前状态
- **收入**：{金额}
- **增长率**：{%}
- **主要客群**：{客群}
- **主要渠道**：{渠道}

### 增长约束
| 维度 | 现状 | 潜力 | 约束 |
|---|---|---|---|
| 新地域 | {现状} | {潜力} | {约束} |
| 新客群 | {现状} | {潜力} | {约束} |
| 新渠道 | {现状} | {潜力} | {约束} |
| 新产品 | {现状} | {潜力} | {约束} |

### 推荐方向
**优先方向**：{方向}
**理由**：{理由}
```

### 第二步：制定增长策略（30 分钟）

**输出**：
```markdown
## 增长策略

### 短期（3 个月）
- {策略 1}
- {策略 2}

### 中期（6 个月）
- {策略 1}
- {策略 2}

### 长期（12 个月）
- {策略 1}
- {策略 2}

### 资源需求
- {资源 1}
- {资源 2}

### 风险与缓解
- **风险**：{风险}
- **缓解**：{缓解措施}
```

## 反模式

- ❌ 同时追求所有方向：聚焦最有潜力的方向
- ❌ 忽视资源约束：考虑团队能力和预算
- ❌ 不衡量：每个方向都要有可衡量的目标
