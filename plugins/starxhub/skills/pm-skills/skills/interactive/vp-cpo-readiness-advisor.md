# VP/CPO 转型顾问（VP/CPO Readiness Advisor）

## 类型
Interactive Skill

## 用途
教练式指导 Director 向 VP/CPO 转型，含 CEO 面试框架

## 耗时
30-90 分钟

## 框架原理

Director→VP/CPO 转型的关键：
- **从产品到业务**：关注业务成果，不是产品特性
- **从执行到战略**：制定产品战略，不是管理项目
- **从团队到组织**：影响整个组织，不是单个团队
- **从功能到商业**：理解商业模型，不是功能设计

## 交互流程

### 第一步：评估准备度（20 分钟）

**核心问题**：
1. 你有业务成果经验吗？
2. 你能制定产品战略吗？
3. 你能影响高管层吗？
4. 你理解商业模型吗？

**输出**：
```markdown
## VP/CPO 准备度评估

### 业务成果
- [ ] 有 P&L 经验
- [ ] 有收入增长经验
- [ ] 有成本控制经验

### 战略能力
- [ ] 能制定产品战略
- [ ] 能与公司战略对齐
- [ ] 能做长期规划

### 影响力
- [ ] 能影响高管层
- [ ] 能跨部门协作
- [ ] 能建立联盟

### 商业敏锐度
- [ ] 理解商业模型
- [ ] 理解市场动态
- [ ] 理解竞争格局

### 总体评分：{分}/100
```

### 第二步：CEO 面试框架（20 分钟）

**CEO 关心的 3 个问题**：
1. **你能带来什么业务成果？**
2. **你的产品战略是什么？**
3. **你如何执行？**

**输出**：
```markdown
## CEO 面试准备

### 问题 1：业务成果
**你的回答**：{回答}
**支撑数据**：{数据}

### 问题 2：产品战略
**你的回答**：{回答}
**支撑数据**：{数据}

### 问题 3：执行计划
**你的回答**：{回答}
**支撑数据**：{数据}
```

### 第三步：制定发展计划（20 分钟）

**输出**：
```markdown
## 发展计划

### 需要发展的能力
- {能力 1}：{发展方式}
- {能力 2}：{发展方式}

### 行动计划
- [ ] {行动 1}
- [ ] {行动 2}

### 导师/教练
- {姓名}：{原因}
```

## 反模式

- ❌ 只谈产品：要谈业务成果
- ❌ 只谈执行：要谈战略
- ❌ 忽视商业：要理解商业模型
