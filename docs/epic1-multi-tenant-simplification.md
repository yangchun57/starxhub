# Epic 1：多租户管理简化

## 一、Epic 概览

| 属性 | 详情 |
|---|---|
| **Epic 名称** | 多租户管理简化 |
| **业务目标** | 降低运营成本，支撑商业化 |
| **成功指标** | ① 新租户上线时间 < 1 小时<br>② 运营成本（人力）< 0.5 人/周<br>③ 租户自助配置率 > 80% |
| **优先级** | 🔴 P0 |
| **预计周期** | 第 1-2 月（6 周） |

---

## 二、用户故事清单

### US-1.1：租户自助创建（预设模板）

**优先级**：🔴 P0  
**依赖**：US-1.4（数据隔离）  
**预计工期**：5 周

**用户故事**：
```
作为租户管理员，
我希望通过选择预设模板快速创建租户，
以便在 10 分钟内完成上线。
```

**验收标准**：
- 提供 3 种预设模板（精简版/标准版/企业版）
- 创建租户后自动初始化数据库和权限
- 创建完成时间 < 10 分钟
- 支持批量创建（CSV 导入）

**技术方案**：
- 模板注册表：JSON/YAML 定义每种模板的配置
- 初始化编排：调用 US-1.4 的 Schema 初始化 + 权限配置
- 异步任务：创建过程异步执行，前端展示进度

**详细 PRD**：见 [US-1.1 PRD](#us-11-prd租户自助创建)

---

### US-1.2：自助管理角色和权限

**优先级**：🔴 P0  
**依赖**：US-1.1（租户创建）  
**预计工期**：3 周

**用户故事**：
```
作为租户管理员，
我希望自助管理角色和权限，
以便不需要开发介入。
```

**验收标准**：
- 支持自定义角色（管理员/开发者/只读）
- 权限粒度到功能模块级别
- 权限变更实时生效
- 支持角色继承和权限模板

**功能点**：
1. 角色管理：创建/编辑/删除角色
2. 权限分配：按功能模块分配权限（读/写/执行）
3. 用户分配：将用户分配到角色
4. 权限审计：记录权限变更日志

---

### US-1.3：租户用量统计

**优先级**：🟠 P1  
**依赖**：US-1.2（权限管理）  
**预计工期**：2 周

**用户故事**：
```
作为租户管理员，
我希望查看租户的用量统计，
以便控制成本。
```

**验收标准**：
- 展示 Token 消耗、API 调用次数
- 支持按用户/功能/时间维度筛选
- 数据延迟 < 5 分钟
- 支持设置用量告警阈值

**统计维度**：
| 维度 | 指标 | 说明 |
|---|---|---|
| Token 消耗 | 输入 Token、输出 Token、总 Token | 按模型类型细分 |
| API 调用 | 调用次数、成功率、平均延迟 | 按接口类型细分 |
| 用户维度 | 每用户 Token、每用户调用次数 | 识别高消耗用户 |
| 时间维度 | 每小时/天/月趋势 | 识别使用高峰 |

### US-1.4：数据隔离自动化

**优先级**：🔴 P0  
**依赖**：无（首个开发）  
**预计工期**：6 周

**用户故事**：
```
作为系统管理员，
我希望新租户的数据自动隔离，
以便避免数据泄露。
```

**验收标准**：
- 每个租户独立数据库 Schema
- 租户间数据查询完全隔离
- 通过安全审计测试
- 新租户 Schema 初始化时间 < 5 分钟

**技术方案**：Schema-per-Tenant
- 连接池路由：根据租户 ID 动态切换 Schema
- 迁移工具：新租户创建时自动执行初始化脚本
- 查询拦截：ORM 层强制注入租户上下文
- 审计日志：记录所有数据访问

**详细 PRD**：见 [US-1.4 PRD](#us-14-prd数据隔离自动化)

### US-1.5：自定义域名和 Logo

**优先级**：🟢 P2

**验收标准**：

## 五、风险与缓解

| 风险 | 影响 | 概率 | 缓解措施 |
|---|---|---|---|
| US-1.4 延期影响后续所有故事 | 高 | 中 | 优先开发 US-1.4，预留 1 周缓冲 |
| Schema 数量过多导致性能问题 | 中 | 低 | 使用 Schema 注册表，定期清理测试租户 |
| 权限配置错误导致安全风险 | 高 | 低 | 权限变更需二次确认，记录审计日志 |
| 批量创建失败导致数据不一致 | 中 | 中 | 事务控制，失败自动回滚 |

## 附录 A：US-1.1 PRD 租户自助创建

### 问题陈述
新租户上线需要系统管理员手动配置，耗时 1 天，阻碍商业化批量获客。

### 技术方案
- 模板注册表：精简版/标准版/企业版
- 初始化编排：Schema 初始化 + 权限配置 + 默认数据
- 异步任务：前端展示进度，WebSocket 推送状态

### 成功指标
- 租户创建时间 < 10 分钟
- 自助创建率 > 80%
- 创建成功率 > 99%

---

## 附录 B：US-1.4 PRD 数据隔离自动化

### 问题陈述
租户间数据隔离依赖人工配置，存在数据泄露风险，无法通过企业安全审计。

### 技术方案
- Schema-per-Tenant：每租户独立 Schema
- 连接池路由：根据租户 ID 动态切换
- ORM 拦截：强制注入租户上下文
- 审计日志：记录所有数据访问

### 成功指标
- 租户创建时间 < 1 小时
- 数据隔离测试通过率 100%
- 跨租户访问漏洞数 = 0
