## 二、用户故事清单

### US-4.1：多语言支持

**优先级**：🔴 P0  
**依赖**：无  
**预计工期**：6 周

**用户故事**：
```
作为开发者，
我希望插件支持我使用的编程语言，
以便在不同项目中获得代码补全。
```

**验收标准**：
- 支持语言：Python、Java、Go、Rust、TypeScript（当前仅 Python）
- 每种语言提供语法高亮、代码补全、错误提示
- 语言识别准确率 > 99%
- 支持语言切换（自动识别 + 手动指定）

**语言支持计划**：
| 语言 | 优先级 | 预计工期 | 模型 |

| Java | 🟠 P1 | 2 周 | 现有模型 + 微调 |
| Go | 🟡 P2 | 1 周 | 现有模型 + 微调 |

### US-4.3：代码审查功能

**优先级**：🟠 P1  
**依赖**：US-4.1（多语言支持）  
**预计工期**：4 周

**用户故事**：
```
作为开发者，
我希望 AI 帮我审查代码，
以便发现潜在问题并提升代码质量。
```

**验收标准**：
- 支持审查维度：代码风格、潜在 Bug、性能问题、安全漏洞
- 审查结果分类：错误（必须修复）、警告（建议修复）、提示（可选）
- 支持一键修复（生成修复代码）
- 审查延迟 < 5 秒（单文件）

**审查规则示例**：
| 类别 | 规则 | 严重级别 |
|---|---|---|
| 代码风格 | 未使用变量 | 警告 |
| 潜在 Bug | 空指针引用 | 错误 |
| 性能 | 循环内重复计算 | 警告 |
| 安全 | SQL 注入风险 | 错误 |
| 安全 | 硬编码密码 | 错误 |

### US-4.4：代码重构建议

**优先级**：🟡 P2  
**依赖**：US-4.3（代码审查）  
**预计工期**：3 周

**用户故事**：
```
作为开发者，
我希望 AI 提供代码重构建议，
以便改善代码结构和可维护性。
```

**验收标准**：
- 支持重构类型：提取函数、提取类、重命名、简化条件
- 重构前展示差异对比（Before/After）
- 支持一键应用重构
- 重构后自动运行测试（如有）

**重构示例**：
```python
# Before
def process(data):
    result = []
    for item in data:
        if item > 0:
            result.append(item * 2)
    return result

# After (AI 建议)
def process(data):
    return [item * 2 for item in data if item > 0]
```

### US-4.5：安全扫描

**优先级**：🟢 P3  
**依赖**：US-4.3（代码审查）  
**预计工期**：3 周

**用户故事**：
```
作为开发者，
我希望 AI 扫描代码中的安全漏洞，
以便提前发现并修复。
```

**验收标准**：
- 支持扫描：SQL 注入、XSS、硬编码密钥、不安全的依赖
- 扫描结果提供修复建议
- 支持扫描整个项目（< 1 分钟）
- 支持生成安全报告（PDF）

**安全规则库**：
| 漏洞类型 | 检测方法 | 修复建议 |
|---|---|---|
| SQL 注入 | 检测字符串拼接 SQL | 使用参数化查询 |
| XSS | 检测未转义的用户输入 | 使用 HTML 转义 |
| 硬编码密钥 | 正则匹配密钥格式 | 使用环境变量 |
| 不安全依赖 | 对比漏洞数据库 | 升级依赖版本 |
